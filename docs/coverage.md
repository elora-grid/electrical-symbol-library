# Coverage and limitations

- **3,155 technical references**: 2200 symbols/diagram references, 155 protection/device functions and 800 GA objects.
- **563 public source records**.
- **334 explicitly labelled ANSI/IEEE forms** and **479 explicitly labelled IEC forms** within the symbol records.
- **6,095 public manufacturer CAD file listings**, counted separately.
- 2355 original SVG concept illustrations. GA objects link to current website previews; CAD/legend downloads use website registration.
- Editorial/source review date: **2026-11-03**; package version: **2.0.0**.

This release is a curated drafting reference, not a complete inventory of IEC 60617 or IEEE 315 records. It does not establish a one-to-one IEC/ANSI crosswalk. Generic concepts, particular graphical forms, protection numbers and GA objects are distinct record types; filenames are counted separately. Multiple records can share generic artwork.

All artwork is independently authored educational concept geometry. It is unitless and not to scale. GA previews are not configured product footprints. Generic drawings do not convey ratings, terminal arrangements, clearances or certified construction details.

Detailed drawing guides remain on [eloragrid.ai](https://eloragrid.ai/tools/electrical-library/guides). Verify applicable publications and project requirements using the linked primary evidence. Coverage counts and format validation do not replace engineering review.
