## What it represents

Commands a valve through an electrical actuator or solenoid.
In a drafting package, connect this reference to the valve tag, actuator supply and command terminals. The associated drawing should trace the process action and valve position feedback; the number identifies the role and does not specify the terminal arrangement, ratings or operating settings.

## How to read it

- Identify the valve tag, actuator supply and command terminals.
- Trace the process action and valve position feedback.

## Drawing checklist

- Label the valve tag, actuator supply and command terminals.
- Cross-reference the process action and valve position feedback.
- Identify the device tag, manual revision and logic drawing that define this implementation.

## Important distinction

An electrically operated valve is an actuator; pressure and flow supervision use separate sensor functions.

## Facts

- ANSI / IEEE function number: 20
