## What it represents

The transformer-fed lamp form identifies an indicator assembly with a documented internal voltage-conversion arrangement. Wiring uses the assembly input rating, while the internal lamp function explains the indication.
This is a convention-specific lookup based on the publisher's IEEE-labelled preview. The geometry here is independently drawn to explain the connection or operation; it is not a certified reproduction of the standard graphic.

## How to read it

- Separate assembly input voltage from internal lamp voltage.
- Read the selected library and the project legend together. A vendor block identifier is meaningful within its named library and is not a universal standard-symbol code.

## Drawing checklist

- State input rating
- Identify assembly terminals
- Name indicated condition

## Important distinction

A lamp's built-in transformer is different from a separately supplied panel control transformer.
