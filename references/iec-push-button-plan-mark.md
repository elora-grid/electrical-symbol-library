# Push button plan mark

Installation plan mark for a momentary push button, such as a door bell push or call button, shown as a small circle with a dot.

[Canonical reference](https://eloragrid.ai/symbols/iec-push-button-plan-mark) · [Structured record](../entries/iec-push-button-plan-mark.json) · [All references](README.md)

Updated: 2026-10-28. Drawing use: GA. Reference families: IEC.

Graphical convention: IEC. Push button.

## What it represents

On installation plans a momentary push button is drawn as a small circle, often with a smaller concentric circle or dot inside, at the wall position. It is used for door bell pushes, assistance call pushes, door release buttons and timer pushes, with a tag clarifying which.
The symbol is usually linked to the device it operates: a bell or chime, an intercom door release or a timer. Reading the link is important because the same push mark serves very different systems on a mixed plan. It does not show whether the push is illuminated, weatherproof or extra-low voltage. Those are scheduled.

## How to read it

- Identify which system the push belongs to from its tag or link.
- Check whether it is outdoors and needs a weatherproof rating.

## Drawing checklist

- Tag the system served.
- State illumination or weatherproofing.
- Show the link to the operated device.

## Important distinction

A schematic push button shows contacts; the plan mark shows the position of the accessory only.

## Facts

- Graphic form: Circle with inner circle or dot
- Common uses: Door bell, call or release button
- Exact standard graphic: Not reproduced here; confirm the form against IEC 60617 and the project legend
