## What it represents

This reference locates photoelectric emitter-receiver switch in Autodesk's IEEE-oriented photoelectric emitter/receiver switches family. A photoelectric emitter-receiver device uses an optical path to determine a switching output. The schematic needs the supply and output connections, while the layout defines the optical arrangement. The public library uses HPE11B16 for its horizontal representation; this is a vendor block name, not an IEEE standards symbol number.
