## What it represents

The return-from-both selector form identifies an operator returning from either outer position to its documented rest position. The middle contact state and both momentary command states require explicit annotations.
This is a convention-specific lookup based on the publisher's IEEE-labelled preview. The geometry here is independently drawn to explain the connection or operation; it is not a certified reproduction of the standard graphic.

## How to read it

- Read release behaviour for each outer command.
- Read the selected library and the project legend together. A vendor block identifier is meaningful within its named library and is not a universal standard-symbol code.

## Drawing checklist

- Identify rest position
- State outer-command actions
- Reference contact schedule

## Important distinction

Return to centre is an operator characteristic; centre off is an electrical contact condition.
