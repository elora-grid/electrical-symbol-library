# Four-position key selector

A four-position key selector provides key-controlled selection among four documented positions.

[Canonical reference](https://eloragrid.ai/symbols/four-position-key-selector) · [Structured record](../entries/four-position-key-selector.json) · [All references](README.md)

Updated: 2026-10-27. Drawing use: Schematic. Reference families: IEC, Manufacturer.

## What it represents

A four-position key selector provides key-controlled selection among four documented positions. The schematic and operator schedule should agree on position numbering and permitted key removal.

## How to read it

- Check the contact table against the front-panel legend.
- The preview is an original explanation of this function. Match the actual drawing convention to its legend and the selected equipment documentation.

## Drawing checklist

- Define position order
- State key removal
- Reference contact terminals

## Important distinction

A keyed four-position operator is different from four separately keyed switches.
