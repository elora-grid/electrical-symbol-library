# Off-delay timer relay

An off-delay timer holds a specified output condition for a documented period after its initiating condition is removed.

[Canonical reference](https://eloragrid.ai/symbols/off-delay-timer-relay) · [Structured record](../entries/off-delay-timer-relay.json) · [All references](README.md)

Updated: 2026-10-27. Drawing use: Schematic. Reference families: IEC, Manufacturer.

## What it represents

An off-delay timer holds a specified output condition for a documented period after its initiating condition is removed. Its auxiliary power requirements depend on the selected timer.

## How to read it

- Determine whether the device needs a continuing supply to complete the delay.
- The preview is an original explanation of this function. Match the actual drawing convention to its legend and the selected equipment documentation.

## Drawing checklist

- Show trigger removal condition
- State delay interval
- Reference supply retention requirements

## Important distinction

Off-delay is not the same as a minimum pulse duration generated when the trigger first arrives.
