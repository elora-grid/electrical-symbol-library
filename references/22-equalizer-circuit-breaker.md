# Equalizer circuit breaker

Switches an equalising connection used in a machine or generator arrangement.

[Canonical reference](https://eloragrid.ai/protection-functions/22-equalizer-circuit-breaker) · [Structured record](../entries/22-equalizer-circuit-breaker.json) · [All references](README.md)

Updated: 2026-10-27. Drawing use: SLD, Schematic. Reference families: IEEE / ANSI.

## What it represents

Switches an equalising connection used in a machine or generator arrangement.
In a drafting package, connect this reference to the equaliser conductors and connected machines. The associated drawing should trace the breaker operating and interlocking circuits; the number identifies the role and does not specify the terminal arrangement, ratings or operating settings.
This designation is useful when reading machine and legacy control drawings. Retain the documented function on an existing drawing and consult the original equipment manual before assigning it to a new design.

## How to read it

- Identify the equaliser conductors and connected machines.
- Trace the breaker operating and interlocking circuits.

## Drawing checklist

- Label the equaliser conductors and connected machines.
- Cross-reference the breaker operating and interlocking circuits.
- Identify the device tag, manual revision and logic drawing that define this implementation.

## Important distinction

The equalising connection has a specific system purpose; do not infer a bus-coupler application solely from the number.

## Facts

- ANSI / IEEE function number: 22
- Drawing context: The equaliser conductors and connected machines
- Application scope: Specialist or legacy machine-control use; interpret with the equipment legend.
