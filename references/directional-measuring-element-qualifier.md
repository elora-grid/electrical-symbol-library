# Directional measuring element qualifier

Arrow qualifier on a measuring relay showing that it operates only for power or current in the marked direction.

[Canonical reference](https://eloragrid.ai/symbols/directional-measuring-element-qualifier) · [Structured record](../entries/directional-measuring-element-qualifier.json) · [All references](README.md)

Updated: 2026-10-28. Drawing use: Schematic, SLD. Reference families: IEC.

## What it represents

A directional qualifier is an arrow added to a measuring relay symbol, showing that the element responds only when the measured quantity flows in the indicated direction. On single-line diagrams the arrow usually points away from or towards the busbar, which tells the reader which faults the element is meant to see.
The arrow depends on correct CT and VT polarity to mean anything in practice. The symbol does not show the characteristic angle or the polarising quantity, so the drawing direction must be confirmed against the relay settings and commissioning tests.

## How to read it

- Note whether the arrow points towards or away from the busbar.
- Check CT and VT polarity supports the shown direction.

## Drawing checklist

- Show arrow relative to the busbar
- State characteristic angle
- Reference polarity checks

## Important distinction

A directional qualifier restricts operation to one direction; a non-directional element operates for either direction.

## Facts

- Meaning: Operation in the arrow direction only
