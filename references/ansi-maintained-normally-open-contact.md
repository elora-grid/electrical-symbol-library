## What it represents

The maintained NO contact form combines a normally-open reference state with documented retention of an operated position. Its release or return mechanism needs a link so the reader does not assume momentary operation.
This is a convention-specific lookup based on the publisher's IEEE-labelled preview. The geometry here is independently drawn to explain the connection or operation; it is not a certified reproduction of the standard graphic.

## How to read it

- Find the action that returns the maintained contact.
- Read the selected library and the project legend together. A vendor block identifier is meaningful within its named library and is not a universal standard-symbol code.

## Drawing checklist

- State initial and retained states
- Identify mechanism reference
- Document return action

## Important distinction

Maintained position describes retention; normally open describes the contact's reference state.
