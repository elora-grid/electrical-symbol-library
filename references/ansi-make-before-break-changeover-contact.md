## What it represents

This reference locates make-before-break changeover contact in Autodesk's IEEE-oriented miscellaneous switches family. A make-before-break changeover contact establishes the next path before releasing the previous path during its documented transfer. The temporary overlap must be understood for the connected circuits. The public library uses HSW1SC7\_F for its horizontal representation; this is a vendor block name, not an IEEE standards symbol number.
