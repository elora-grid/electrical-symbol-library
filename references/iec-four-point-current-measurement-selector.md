## What it represents

This representation identifies selection among four current-measurement points. The additional measurement point expands the selected current-input circuits while retaining a common meter. Each position therefore needs an unambiguous circuit identity.
Provide all four measurement references and the actual terminal scheme. A voltage selector with the same number of positions is not an interchangeable current-measurement switch.
