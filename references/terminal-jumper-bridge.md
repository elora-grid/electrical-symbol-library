# Terminal jumper bridge

A terminal bridge intentionally connects specified terminal points to a common potential.

## What it represents

A terminal bridge intentionally connects specified terminal points to a common potential. The drawing needs the actual bridged positions rather than an undifferentiated line across an entire terminal strip.

## How to read it

- Check skipped positions and separated terminal levels in the bridge plan.
- The preview is an original explanation of this function. Match the actual drawing convention to its legend and the selected equipment documentation.

## Drawing checklist

- List bridged terminals
- Identify common potential
- Reference bridge component

## Important distinction

A bridge is an intentional common connection; close physical spacing does not establish electrical continuity.
