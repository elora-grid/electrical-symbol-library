# Four-position maintained selector

A four-position maintained selector provides four stable operating choices.

## What it represents

A four-position maintained selector provides four stable operating choices. Each contact's state across those choices is recorded in a schedule instead of trying to express the complete logic in one contact outline.

## How to read it

- Verify the sequence and order of all four positions.
- The preview is an original explanation of this function. Match the actual drawing convention to its legend and the selected equipment documentation.

## Drawing checklist

- Name four positions
- Provide switching table
- Identify common operator tag

## Important distinction

Four positions do not imply four independent contact poles.
