## What it represents

The screened-transformer form identifies a separate electrostatic-screen feature associated with the windings. Follow the screen connection as its own conductor, with the manufacturer's designated earth or bonding arrangement.
This is a convention-specific lookup based on the publisher's IEEE-labelled preview. The geometry here is independently drawn to explain the connection or operation; it is not a certified reproduction of the standard graphic.

## How to read it

- The screen lead is not an additional load winding.
- Read the selected library and the project legend together. A vendor block identifier is meaningful within its named library and is not a universal standard-symbol code.

## Drawing checklist

- Identify screen terminal
- Show bonding connection
- Reference selected transformer instructions

## Important distinction

An interwinding screen differs from the transformer's magnetic core and from a protective-earth symbol beside its enclosure.
