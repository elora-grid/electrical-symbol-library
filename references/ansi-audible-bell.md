## What it represents

This reference locates audible bell in Autodesk's IEEE-oriented miscellaneous family. A bell indication identifies an audible annunciation output in a control circuit. The public library uses HAN1B for its horizontal representation; this is a vendor block name, not an IEEE standards symbol number.
