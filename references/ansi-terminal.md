## What it represents

The round terminal form identifies a connection point in the vendor's IEEE-oriented library. Terminal identity and wire-number conventions tell the reader whether it is a physical terminal, a diagram connection reference or another declared interface.
This is a convention-specific lookup based on the publisher's IEEE-labelled preview. The geometry here is independently drawn to explain the connection or operation; it is not a certified reproduction of the standard graphic.

## How to read it

- Use the terminal plan to resolve physical position.
- Read the selected library and the project legend together. A vendor block identifier is meaningful within its named library and is not a universal standard-symbol code.

## Drawing checklist

- State terminal identifier
- Show connected conductors
- Reference terminal-strip plan

## Important distinction

A terminal mark is different from a wire-junction dot when the drawing assigns it a physical connection identity.
