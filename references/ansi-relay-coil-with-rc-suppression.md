## What it represents

The RC-suppressed relay form associates resistance and capacitance with the operating circuit. Its actual network location and compatibility come from the selected assembly, while the contact circuit remains separately referenced.
This is a convention-specific lookup based on the publisher's IEEE-labelled preview. The geometry here is independently drawn to explain the connection or operation; it is not a certified reproduction of the standard graphic.

## How to read it

- Determine whether suppression is in the coil, socket or external wiring.
- Read the selected library and the project legend together. A vendor block identifier is meaningful within its named library and is not a universal standard-symbol code.

## Drawing checklist

- Show network location
- State coil supply
- Reference compatible suppression module

## Important distinction

An RC network and a diode suppressor are different component arrangements, not interchangeable graphic decorations.
