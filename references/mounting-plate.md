# Mounting plate

An enclosure mounting surface supporting the selected internal components.

## What it represents

A mounting plate provides an installation surface within an enclosure. Its size, material, location and fitting depend on the selected enclosure system and accessories. An internal panel layout uses it to organise component placement and interface references.

## How to read it

- Read the plate position relative to the enclosure frame and doors.
- Use the selected system documentation for fitting and dimensions.

## Drawing checklist

- Reference the enclosure and plate model.
- Coordinate internal component placement.
- Keep fixing and interface information documented.

## Important distinction

A generic rectangle does not establish a fabrication size or drilling layout. Use the selected plate and component information.
