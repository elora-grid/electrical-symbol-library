# Differential voltmeter

A differential voltmeter indicates a difference between documented voltage inputs.

[Canonical reference](https://eloragrid.ai/symbols/differential-voltmeter) · [Structured record](../entries/differential-voltmeter.json) · [All references](README.md)

Updated: 2026-10-27. Drawing use: SLD, Schematic. Reference families: IEC, Manufacturer.

## What it represents

A differential voltmeter indicates a difference between documented voltage inputs. Its reference and compared circuits must be identifiable so the indicated difference has a defined meaning.

## How to read it

- Verify the input connection arrangement against the actual instrument diagram.
- The preview is an original explanation of this function. Match the actual drawing convention to its legend and the selected equipment documentation.

## Drawing checklist

- Identify both compared inputs
- State polarity/reference
- Reference measurement range

## Important distinction

A differential voltage indicator is different from a transformer differential protection function.
