# Telephone set symbol

Symbol for a telephone instrument, drawn as a handset shape, used on communication layouts and schematics.

[Canonical reference](https://eloragrid.ai/symbols/iec-telephone-set-symbol) · [Structured record](../entries/iec-telephone-set-symbol.json) · [All references](README.md)

Updated: 2026-10-28. Drawing use: GA, Schematic. Reference families: IEC.

Graphical convention: IEC. Telephone set.

## What it represents

The telephone set symbol shows the instrument itself, usually as a stylised handset over a base or a circle with a handset. It appears on communication system diagrams, lift and emergency phone schematics and on plans where a fixed phone is supplied.
Where a phone is provided as part of a system, such as a lift car phone, help point or emergency phone, the symbol distinguishes the supplied device from a simple outlet. The plan then tags the device type. The symbol does not tell you whether the instrument is analogue, IP or hands-free.

## How to read it

- Check whether the instrument is supplied or only the outlet.
- Read the device type tag.

## Drawing checklist

- State instrument type.
- Show its outlet or line.
- Note emergency use where relevant.

## Important distinction

A telephone outlet is the termination; the telephone set symbol is the instrument.
