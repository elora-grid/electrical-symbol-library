# Current-measuring shunt

A current-measuring shunt produces a documented voltage drop corresponding to current through a resistive element.

[Canonical reference](https://eloragrid.ai/symbols/current-measuring-shunt) · [Structured record](../entries/current-measuring-shunt.json) · [All references](README.md)

Updated: 2026-10-27. Drawing use: SLD, Schematic. Reference families: IEC, Manufacturer.

## What it represents

A current-measuring shunt produces a documented voltage drop corresponding to current through a resistive element. The drawing must distinguish the current path from the sensing leads.

## How to read it

- Identify the separate measurement connections where the selected shunt provides them.
- The preview is an original explanation of this function. Match the actual drawing convention to its legend and the selected equipment documentation.

## Drawing checklist

- State current and voltage-drop rating
- Show sense leads
- Reference polarity/scaling

## Important distinction

A shunt produces a voltage measurement without a current-transformer secondary.
