## What it represents

The potential-transformer form identifies a voltage measurement interface in the IEEE-oriented vendor library. Power connection, winding polarity and secondary protection are read as instrument-transformer information rather than as a general power-supply transformer.
This is a convention-specific lookup based on the publisher's IEEE-labelled preview. The geometry here is independently drawn to explain the connection or operation; it is not a certified reproduction of the standard graphic.

## How to read it

- Trace both primary voltage connections and the secondary input circuit.
- Read the selected library and the project legend together. A vendor block identifier is meaningful within its named library and is not a universal standard-symbol code.

## Drawing checklist

- State VT ratio
- Identify primary/secondary terminals
- Show protection and earthing references

## Important distinction

Potential transformer is a common name for a VT; a shared word does not make it a CT.
