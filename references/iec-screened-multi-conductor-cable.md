# Screened multi-conductor cable

Several conductors enclosed together within one drawn screen, showing an overall shield around a multicore cable.

[Canonical reference](https://eloragrid.ai/symbols/iec-screened-multi-conductor-cable) · [Structured record](../entries/iec-screened-multi-conductor-cable.json) · [All references](README.md)

Updated: 2026-10-28. Drawing use: Schematic. Reference families: IEC.

Graphical convention: IEC. Overall screened multicore form.

## What it represents

This form draws one screen outline around a group of conductors to show an overall or collective screen. It is common on instrument multicore cables, field bus trunks and multi-pair analogue cables run from field junction boxes back to a marshalling cabinet.
An overall screen is different from individually screened pairs. If each pair also carries its own screen, the drawing needs separate outlines for each pair inside the overall one, otherwise a reader will terminate only one drain. The symbol does not give the core count beyond what is drawn, so the cable schedule still controls the core and pair allocation.

## How to read it

- Count the conductors drawn inside the outline and compare with the cable schedule.
- Check whether individual pair screens are also shown.

## Drawing checklist

- State the cable tag on the screened group.
- Show where the overall screen is terminated.
- Distinguish overall screens from individual pair screens.

## Important distinction

An overall screened cable shields all its cores together; a screened twisted pair shields one pair on its own.
