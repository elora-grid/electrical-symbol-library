# Double voltmeter

Instrument with two voltage movements in one case, showing running and incoming voltage side by side for synchronising.

[Canonical reference](https://eloragrid.ai/symbols/double-voltmeter) · [Structured record](../entries/double-voltmeter.json) · [All references](README.md)

Updated: 2026-10-28. Drawing use: SLD, Schematic. Reference families: IEC, Manufacturer.

## What it represents

A double voltmeter contains two voltage measuring elements, usually reading the running busbar and the incoming generator or feeder. Mounted on a synchronising panel next to the double frequency meter and synchroscope, it lets the operator match voltages before closing.
The two inputs must come from VTs with equivalent ratios and the same phase pair, otherwise the comparison is misleading. The symbol does not show the switching that selects which incoming source is connected to the instrument.

## How to read it

- Identify which input is running and which is incoming.
- Check the synchronising selector that switches the inputs.

## Drawing checklist

- Label both inputs
- Show VT ratios
- Reference sync selector switch

## Important distinction

A double voltmeter shows both voltages; a differential voltmeter shows only their difference.
