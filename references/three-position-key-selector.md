# Three-position key selector

A three-position key selector combines position selection with a key-operated mechanism.

[Canonical reference](https://eloragrid.ai/symbols/three-position-key-selector) · [Structured record](../entries/three-position-key-selector.json) · [All references](README.md)

Updated: 2026-10-27. Drawing use: Schematic. Reference families: IEC, Manufacturer.

## What it represents

A three-position key selector combines position selection with a key-operated mechanism. Stable positions, return behaviour and key-removal conditions are all required for a complete control description.

## How to read it

- Do not assume that a removable key is allowed in every selected position.
- The preview is an original explanation of this function. Match the actual drawing convention to its legend and the selected equipment documentation.

## Drawing checklist

- List positions
- State key-removal conditions
- Cross-reference contact schedule

## Important distinction

Key operation adds access control to a selector; it does not change its electrical contact ratings.
