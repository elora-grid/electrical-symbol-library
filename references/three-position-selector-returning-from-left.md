# Three-position selector returning from left

This three-position selector has a documented spring return from its left position.

Updated: 2026-10-27. Drawing use: Schematic. Reference families: IEC, Manufacturer.

## What it represents

This three-position selector has a documented spring return from its left position. Other positions may be stable or have different behaviour, so the return direction must remain explicit.

## How to read it

- Establish the rest position and the state after the left-hand command is released.
- The preview is an original explanation of this function. Match the actual drawing convention to its legend and the selected equipment documentation.

## Drawing checklist

- Label rest position
- Show return direction
- Provide position/contact schedule

## Important distinction

Return from left is not equivalent to return from both outer positions.
