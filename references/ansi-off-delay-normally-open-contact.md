## What it represents

The off-delay NO contact form identifies instant closing on the documented operation and delayed opening on release. This sequence is distinct from merely marking a contact as normally open, and auxiliary-supply behaviour must be checked separately.
This is a convention-specific lookup based on the publisher's IEEE-labelled preview. The geometry here is independently drawn to explain the connection or operation; it is not a certified reproduction of the standard graphic.

## How to read it

- Read instant close and delayed release as two distinct transitions.
- Read the selected library and the project legend together. A vendor block identifier is meaningful within its named library and is not a universal standard-symbol code.

## Drawing checklist

- Link trigger/timer
- State release interval
- Reference supply-loss behaviour

## Important distinction

Off-delay NO output is not equivalent to an on-delay NC output under every operating sequence.
