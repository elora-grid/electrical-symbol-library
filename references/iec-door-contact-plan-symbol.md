# Door contact plan symbol

Security plan symbol for a magnetic contact that signals whether a door or window is open.

[Canonical reference](https://eloragrid.ai/symbols/iec-door-contact-plan-symbol) · [Structured record](../entries/iec-door-contact-plan-symbol.json) · [All references](README.md)

Updated: 2026-10-28. Drawing use: GA. Reference families: IEC.

Graphical convention: IEC. Door contact.

## What it represents

Magnetic door contacts use a reed switch on the frame and a magnet on the door. Security plans draw a small pair of rectangles or a contact mark at the door head, tagged DC, with the zone number.
Door contacts are used both for intruder alarm and for access control door monitoring, where they detect forced or held-open doors. The plan should state which system or both. The symbol does not tell you whether the contact is surface or flush, or high-security balanced type.

## How to read it

- Check which system receives the signal.
- Check surface or flush type in schedule.

## Drawing checklist

- Tag zone or door number.
- State contact type.
- Coordinate with door hardware.

## Important distinction

A limit switch in machine control detects mechanical position; a door contact is a security monitoring device.

## Facts

- Operating principle: Reed switch and magnet
- Systems: Intruder alarm and access control
