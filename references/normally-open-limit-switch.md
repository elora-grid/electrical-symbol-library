# Normally-open limit switch

A normally-open limit switch closes when the documented mechanical travel or position condition actuates it.

## What it represents

A normally-open limit switch closes when the documented mechanical travel or position condition actuates it. It identifies a position input rather than the complete mechanical arrangement.

## How to read it

- State which equipment position actuates the switch.
- The preview is an original explanation of this function. Match the actual drawing convention to its legend and the selected equipment documentation.

## Drawing checklist

- Name monitored position
- Label actuator reference
- Show contact terminals

## Important distinction

A limit switch responds to mechanical position; a pushbutton responds to an operator action.
