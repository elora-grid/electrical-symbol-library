# Resistor

A resistive component with its value and purpose documented separately.

[Canonical reference](https://eloragrid.ai/symbols/resistor) · [Structured record](../entries/resistor.json) · [All references](README.md)

Updated: 2026-10-27. Drawing use: Schematic. Reference families: IEC, IEEE / ANSI.

## What it represents

A resistor representation identifies a resistive component in a circuit. Different drawing conventions can use different basic outlines, while additional qualifiers distinguish variable resistors, shunts or heating elements. The value, rating and purpose are separate annotations.
In power-system controls, a resistive component may belong to measurement, suppression or another specific circuit. A neutral-earthing resistor is a specialised system component and should not be identified only with an unqualified generic resistor mark.

## How to read it

- Read the component value and application label alongside the mark.
- Check whether a qualifier identifies a variable device, heater, shunt or another variant.

## Drawing checklist

- Reference resistance and rating information.
- Identify the circuit purpose.
- Distinguish specialised assemblies from a generic component.

## Important distinction

IEC-style rectangular and other conventional resistor depictions can describe the same component concept, but qualifiers and documentation still matter.

## Facts

- Component data: Resistance and power rating
- Variants: Fixed, variable, shunt and other applications
- Graphic convention: Check the drawing legend
- Public Autodesk reference names: HRE1B, VRE1B (vendor identifiers, not IEC symbol IDs)
