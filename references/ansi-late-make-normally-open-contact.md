## What it represents

The delayed NO contact form identifies later operation in a documented contact sequence. The drafting reference must say which contacts or mechanism establish the sequence rather than interpreting geometric spacing as a time interval.
This is a convention-specific lookup based on the publisher's IEEE-labelled preview. The geometry here is independently drawn to explain the connection or operation; it is not a certified reproduction of the standard graphic.

## How to read it

- Read the selected device's contact sequence.
- Read the selected library and the project legend together. A vendor block identifier is meaningful within its named library and is not a universal standard-symbol code.

## Drawing checklist

- Identify common operator
- Label late-closing transition
- Reference sequence documentation

## Important distinction

A delayed sequence qualifier is not necessarily an independently adjustable timer function.
