## What it represents

This reference locates key-operated normally-open switch in Autodesk's IEEE-oriented miscellaneous switches family. A key-operated NO switch closes a contact through an authorised key mechanism. The schematic needs the operating positions and any key-removal restrictions to explain access control. The public library uses HPB11KS for its horizontal representation; this is a vendor block name, not an IEEE standards symbol number.
Read the operating mechanism and the contact reference state together. Cross-reference every associated contact to the same device and show which movement, signal or reset changes its condition; the symbol alone does not establish the complete switching sequence.
