## What it represents

This reference locates bidirectional breakdown diode in Autodesk's IEEE-oriented semiconductor components family. A bidirectional breakdown diode provides a documented voltage-limiting semiconductor path in both polarities. Its working voltage and surge characteristics determine the protective application. The public library uses HDI1\_S00647 for its horizontal representation; this is a vendor block name, not an IEEE standards symbol number.
Follow the actual current path and terminal polarity in the surrounding circuit. The symbol identifies an electrical function; voltage, current, energy limits and the device package pinout come from the selected component data rather than from the outline.
Read working-voltage and breakdown specifications separately. Bidirectional protection does not make the component a controllable power switch.
