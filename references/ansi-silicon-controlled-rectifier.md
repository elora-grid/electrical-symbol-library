## What it represents

The SCR form identifies a thyristor power path with a separate gate trigger connection. Following anode, cathode and gate independently explains the difference between the controlled power circuit and its drive circuit.
This is a convention-specific lookup based on the publisher's IEEE-labelled preview. The geometry here is independently drawn to explain the connection or operation; it is not a certified reproduction of the standard graphic.

## How to read it

- Locate the gate reference before interpreting the trigger supply.
- Read the selected library and the project legend together. A vendor block identifier is meaningful within its named library and is not a universal standard-symbol code.

## Drawing checklist

- Label anode/cathode/gate
- Reference gate drive
- State power-circuit rating

## Important distinction

An SCR is different from a bidirectional TRIAC, and a gate lead is not an additional load terminal.
