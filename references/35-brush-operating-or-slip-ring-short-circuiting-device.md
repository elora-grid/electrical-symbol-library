## What it represents

Changes the brush or slip-ring arrangement as part of a wound-rotor machine sequence.
In a drafting package, connect this reference to the brush mechanism and slip-ring circuit. The associated drawing should trace the mechanism drive and proof-of-position contacts; the number identifies the role and does not specify the terminal arrangement, ratings or operating settings.
This designation is useful when reading machine and legacy control drawings. Retain the documented function on an existing drawing and consult the original equipment manual before assigning it to a new design.

## How to read it
