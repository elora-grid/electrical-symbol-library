# Sensor terminal block

A sensor terminal organises supply, return and signal connections for a documented sensor wiring arrangement.

[Canonical reference](https://eloragrid.ai/symbols/sensor-terminal-block) · [Structured record](../entries/sensor-terminal-block.json) · [All references](README.md)

Updated: 2026-10-27. Drawing use: Schematic. Reference families: Manufacturer.

## What it represents

A sensor terminal organises supply, return and signal connections for a documented sensor wiring arrangement. Multilevel construction may separate the signal path from bridged supply potentials.

## How to read it

- Follow each level to the sensor's supply and output terminals.
- The preview is an original explanation of this function. Match the actual drawing convention to its legend and the selected equipment documentation.

## Drawing checklist

- Identify signal level
- Show supply bridges
- Reference sensor conductor count

## Important distinction

A sensor terminal's physical levels do not imply that all conductors are electrically common.
