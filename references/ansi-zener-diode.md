## What it represents

The Zener diode form identifies a documented reverse-breakdown operating function. Its polarity, reference voltage and associated current limitation establish how the circuit uses the component; the modified junction outline is not a complete regulator circuit.
This is a convention-specific lookup based on the publisher's IEEE-labelled preview. The geometry here is independently drawn to explain the connection or operation; it is not a certified reproduction of the standard graphic.

## How to read it

- Read the current-limiting path alongside the Zener connection.
- Read the selected library and the project legend together. A vendor block identifier is meaningful within its named library and is not a universal standard-symbol code.

## Drawing checklist

- State nominal voltage/power
- Preserve polarity
- Reference bias/current limitation

## Important distinction

A Zener operating function differs from an ordinary rectifier diode's intended reverse-voltage service.
