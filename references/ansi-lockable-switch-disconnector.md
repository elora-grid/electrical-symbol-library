## What it represents

The lockable switch-disconnector form combines load switching, isolation and a documented locking provision. These are separate capabilities recorded against the same device, rather than inferred from a single contact gap or padlock outline.
This is a convention-specific lookup based on the publisher's IEEE-labelled preview. The geometry here is independently drawn to explain the connection or operation; it is not a certified reproduction of the standard graphic.

## How to read it

- Identify the permitted locking state in the operator schedule.
- Read the selected library and the project legend together. A vendor block identifier is meaningful within its named library and is not a universal standard-symbol code.

## Drawing checklist

- Record switching duty
- State locking position
- Reference handle arrangement

## Important distinction

Adding a locking modifier to a switch does not prove that it has the isolation function of a switch-disconnector.
