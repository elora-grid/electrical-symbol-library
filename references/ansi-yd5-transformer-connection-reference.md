## What it represents

This reference locates yd5 transformer connection reference in Autodesk's IEEE-oriented 3 phase transformers family. Yd5 combines an HV-side star winding designation with an LV-side delta designation and clock group 5. The letters describe connection topology; the final number identifies the phase relationship recorded with the transformer connection diagram. It is different from the voltage ratio or the number of terminals. The public library uses HXF1T23 for its horizontal representation; this is a vendor block name, not an IEEE standards symbol number.
