# Active-power indicator

An active-power indicator displays real power derived from its specified measurement inputs.

[Canonical reference](https://eloragrid.ai/symbols/active-power-indicator) · [Structured record](../entries/active-power-indicator.json) · [All references](README.md)

Updated: 2026-10-27. Drawing use: SLD, Schematic. Reference families: IEC, Manufacturer.

## What it represents

An active-power indicator displays real power derived from its specified measurement inputs. On an SLD it identifies the monitored feeder or source; the schematic supplies phase and ratio details.

## How to read it

- Identify the power-flow sign reference at the measurement location.
- The preview is an original explanation of this function. Match the actual drawing convention to its legend and the selected equipment documentation.

## Drawing checklist

- Name measured feeder
- Show current/voltage inputs
- State import/export convention

## Important distinction

Active-power indication differs from reverse-power protection, even when both use the same measured quantity.
