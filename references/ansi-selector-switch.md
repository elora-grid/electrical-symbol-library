## What it represents

The two-position maintained selector form links an operator position to a defined contact state. A position/contact schedule supplies the full control meaning; the operator label alone cannot describe multiple contact blocks on the same handle.
This is a convention-specific lookup based on the publisher's IEEE-labelled preview. The geometry here is independently drawn to explain the connection or operation; it is not a certified reproduction of the standard graphic.

## How to read it

- Read the selected position against the contact table.
- Read the selected library and the project legend together. A vendor block identifier is meaningful within its named library and is not a universal standard-symbol code.

## Drawing checklist

- Name operator positions
- Provide contact-state schedule
- Identify terminal pairs

## Important distinction

Operator positions count mechanical choices, while poles count electrical paths.
