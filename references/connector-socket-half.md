# Connector socket half

## What it represents

A socket-half representation identifies the mating interface for a detachable plug. The drawing records the pin and circuit identity, including the defined viewing orientation.

## How to read it

- Read connector pin orientation from the documented front or wiring view.
- The preview is an original explanation of this function. Match the actual drawing convention to its legend and the selected equipment documentation.

## Drawing checklist

- Name socket and pin
- Reference mating plug
- State pin-view convention

## Important distinction

Socket appearance on a schematic does not define the product's mechanical dimensions.
