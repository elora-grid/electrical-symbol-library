## What it represents

A combined photoelectric sensor contains an emitter and a receiver within the same documented sensing unit. This entry identifies the normally closed emitter-receiver ac driven 3 pin form in the publisher's IEC-context family.
A reflective sensing arrangement can detect a passing object or a change in returned light and send the result to a control input. The normally-closed designation starts with a conducting output or closed contact in the documented reference condition; operation changes that state. This is the AC-supplied form. Supply and switched output must be checked separately rather than substituting a DC sensor connection diagram.
The combined housing does not establish whether a reflector or the target returns the light. Sensing mode, light-on or dark-on selection and pin functions need the selected product diagram.
