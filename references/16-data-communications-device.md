## What it represents

Identifies equipment carrying data between control, protection or monitoring devices.
In a drafting package, connect this reference to the communication medium and connected endpoints. The associated drawing should trace the network ports, link identifiers and architecture drawing; the number identifies the role and does not specify the terminal arrangement, ratings or operating settings.

## How to read it

- Identify the communication medium and connected endpoints.
- Trace the network ports, link identifiers and architecture drawing.

## Drawing checklist

- Label the communication medium and connected endpoints.
- Cross-reference the network ports, link identifiers and architecture drawing.
- Identify the device tag, manual revision and logic drawing that define this implementation.

## Important distinction

Device 16 describes the communication role; its suffix and network legend determine whether the item is a switch, router or other device.

## Facts

- ANSI / IEEE function number: 16
- Drawing context: The communication medium and connected endpoints
- Application scope: Protection or apparatus-control role; exact implementation is defined by the equipment documentation.
