# Star-delta transformer

A star-delta transformer connects one winding set in star and the other in delta.

## What it represents

A star-delta transformer connects one winding set in star and the other in delta. The notation identifies winding topology; a clock-number or equivalent phase-displacement designation is still needed where system phase relationships matter.

## How to read it

- Read which side is star from the declared primary and secondary labels.
