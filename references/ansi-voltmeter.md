## What it represents

The voltage-meter form identifies an indicating instrument connected to a documented voltage measurement. Its measurement pair, selected source and any VT ratio must be read separately from the instrument's auxiliary supply.
This is a convention-specific lookup based on the publisher's IEEE-labelled preview. The geometry here is independently drawn to explain the connection or operation; it is not a certified reproduction of the standard graphic.

## How to read it

- Trace both voltage inputs to establish the measured quantity.
- Read the selected library and the project legend together. A vendor block identifier is meaningful within its named library and is not a universal standard-symbol code.

## Drawing checklist

- Name measured voltage
- State direct/VT connection
- Reference measuring range

## Important distinction

A voltage meter displays a quantity; a voltage relay applies an operating criterion and issues an output.
