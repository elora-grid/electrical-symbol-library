# Temperature indicator

A temperature indicator displays the temperature derived from its specified sensor or input.

[Canonical reference](https://eloragrid.ai/symbols/temperature-indicator) · [Structured record](../entries/temperature-indicator.json) · [All references](README.md)

Updated: 2026-10-27. Drawing use: SLD, Schematic. Reference families: IEC, Manufacturer.

## What it represents

A temperature indicator displays the temperature derived from its specified sensor or input. The drawing links it to the sensor location and input characteristic.

## How to read it

- Confirm whether the input is thermocouple, resistance or a transmitter signal.
- The preview is an original explanation of this function. Match the actual drawing convention to its legend and the selected equipment documentation.

## Drawing checklist

- Identify sensor tag
- State sensor/input type
- Reference displayed unit and range

## Important distinction

A temperature display does not imply a separate temperature-switch contact is provided.

## Facts

- Drawing role: Indicated quantity
