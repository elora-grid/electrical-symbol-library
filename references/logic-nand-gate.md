## What it represents

A logic gate that inverts the result of an AND operation.
On a schematic, identify the input truth states and the output inversion indication and trace the output logic state and downstream input. Keep the component tag and signal/reference names consistent across the control drawing, terminal schedule and device documentation.
The inversion bubble concerns logical polarity; it does not identify a normally-closed physical contact.
Terminal letters describe electrical roles, not package pin numbers. Check the selected public datasheet for the actual pin assignment, polarity and any internally connected terminals before completing the drawing.
