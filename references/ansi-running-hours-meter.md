## What it represents

The hour-meter form identifies elapsed-time accumulation while its specified enabling condition is active. The circuit should make clear whether this condition is supply energisation, equipment running feedback or another declared event.
This is a convention-specific lookup based on the publisher's IEEE-labelled preview. The geometry here is independently drawn to explain the connection or operation; it is not a certified reproduction of the standard graphic.

## How to read it

- Read the enable circuit instead of assuming it counts actual shaft running.
- Read the selected library and the project legend together. A vendor block identifier is meaningful within its named library and is not a universal standard-symbol code.

## Drawing checklist

- Identify enable contact
- State counted condition
- Reference retention/reset

## Important distinction

An hour meter accumulates duration; an operation counter counts discrete events.
