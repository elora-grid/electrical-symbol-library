## What it represents

The jack-side connector form identifies the mating interface for a separately referenced plug. Terminal naming and pin-view information prevent accidental reversal when translating between a front view and a wiring view.
This is a convention-specific lookup based on the publisher's IEEE-labelled preview. The geometry here is independently drawn to explain the connection or operation; it is not a certified reproduction of the standard graphic.

## How to read it

- Read the socket's pin orientation from its documented view.
- Read the selected library and the project legend together. A vendor block identifier is meaningful within its named library and is not a universal standard-symbol code.

## Drawing checklist

- Name socket and pin
- Reference mating plug
- Identify wiring/front view

## Important distinction

A socket-half schematic form does not describe mechanical shell dimensions or keying.
