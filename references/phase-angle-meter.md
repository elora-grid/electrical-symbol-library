# Phase-angle meter

A phase-angle meter indicates the phase relationship between documented signals.

[Canonical reference](https://eloragrid.ai/symbols/phase-angle-meter) · [Structured record](../entries/phase-angle-meter.json) · [All references](README.md)

Updated: 2026-10-27. Drawing use: SLD, Schematic. Reference families: IEC, Manufacturer.

## What it represents

A phase-angle meter indicates the phase relationship between documented signals. The schematic names the reference and compared input so the displayed angle is interpretable.

## How to read it

- Check which signal is the reference and which is compared.

## Drawing checklist

- Label compared inputs
- State reference convention
- Reference measurement range

## Important distinction

A phase-angle meter is not automatically a synchronism-check permissive relay.
