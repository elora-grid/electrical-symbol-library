# Permissive control device

Permits or prevents an equipment operation according to a selected control condition.

[Canonical reference](https://eloragrid.ai/protection-functions/69-permissive-control-device) · [Structured record](../entries/69-permissive-control-device.json) · [All references](README.md)

Updated: 2026-10-27. Drawing use: SLD, Schematic. Reference families: IEEE / ANSI.

## What it represents

Permits or prevents an equipment operation according to a selected control condition.
In a drafting package, connect this reference to the permissive selector or control input. The associated drawing should trace the inhibited or enabled operating command; the number identifies the role and does not specify the terminal arrangement, ratings or operating settings.

## How to read it

- Identify the permissive selector or control input.
- Trace the inhibited or enabled operating command.

## Drawing checklist

- Label the permissive selector or control input.
- Cross-reference the inhibited or enabled operating command.
- Identify the device tag, manual revision and logic drawing that define this implementation.

## Important distinction

A permissive control establishes command authority; a numbered interlocking relay may separately verify apparatus state.

## Facts

- ANSI / IEEE function number: 69
- Drawing context: The permissive selector or control input
- Application scope: Protection or apparatus-control role; exact implementation is defined by the equipment documentation.
