# Main earthing terminal

The terminal or bar where protective conductors, bonding conductors and the earthing conductor of an installation meet.

[Canonical reference](https://eloragrid.ai/symbols/iec-main-earthing-terminal) · [Structured record](../entries/iec-main-earthing-terminal.json) · [All references](README.md)

Updated: 2026-10-28. Drawing use: SLD, Schematic. Reference families: IEC.

Graphical convention: IEC. Main earthing terminal.

## What it represents

The main earthing terminal is the hub of an installation's earthing. Installation guidance describes it as the point that provides the main equipotential connection, with the earthing conductor to the electrode, main bonding conductors to metallic services and protective conductors to circuits all landed on it. Earthing schematics draw it as a bar with labelled connections.
The symbol shows the hub but not the size of each conductor, which must be scheduled. It also does not show the removable test link, which should be drawn on the electrode connection. In larger sites, sub-main earth bars are separate items connected back to the MET.

## How to read it

- Check that every main bonding conductor lands on the MET.
- Look for the test link on the electrode conductor.

## Drawing checklist

- Label each conductor on the MET.
- Show earthing conductor and test link.
- Schedule bonding conductor sizes.

## Important distinction

The main earthing terminal is the installation's earthing hub; a protective-earth terminal block is a single terminal in a panel.

## Facts

- Graphic cue: Bar with earth symbol and several labelled connections
- Connected items: Earthing conductor, main bonds and circuit protective conductors
