# Spark-gap protective element

A spark-gap element provides a documented breakdown path across separated electrodes.

Updated: 2026-10-27. Drawing use: SLD, Schematic. Reference families: IEC, Manufacturer.

## What it represents

A spark-gap element provides a documented breakdown path across separated electrodes. Its drawing identifies the protective location without implying the same behaviour as a semiconductor clamp.

## How to read it

- Read the gap and protection characteristics from the actual device documentation.

## Drawing checklist

- Identify connected points
- Reference protection rating
- Show discharge path

## Important distinction

A spark-gap element and a varistor use different protective mechanisms.
