# Maintained normally-open pushbutton

A maintained NO pushbutton stays in its actuated condition until the documented return operation.

Updated: 2026-10-27. Drawing use: Schematic. Reference families: IEC, Manufacturer.

## What it represents

A maintained NO pushbutton stays in its actuated condition until the documented return operation. The control sequence must account for the retained input rather than assuming a momentary pulse.

## How to read it

- Identify the release method and any reset interlock.

## Drawing checklist

- State retained position
- Document return action
- Show contact reference

## Important distinction

A maintained pushbutton is different from a spring-return momentary operator.
