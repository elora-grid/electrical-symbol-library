## What it represents

A DC motor represents a documented DC electrical load whose armature and any field winding arrangements need to be identified. The generic function does not select the excitation method.

## How to read it

- Trace armature polarity and the control or starting circuit.
- The preview is an original explanation of this function. Match the actual drawing convention to its legend and the selected equipment documentation.

## Drawing checklist

- State DC voltage and rating
- Identify armature terminals
- Reference excitation arrangement

## Important distinction

A generic DC motor does not imply permanent-magnet or series-field construction.

## Facts

- Drawing role: Rotating or linear load
- Representation scope: Functional concept; not an official standard graphic or a product footprint
- Public vendor block reference: HMO1M6, VMO1M6 (Autodesk identifiers; not IEC symbol numbers)
- Identifier status: The short label is a functional lookup label, not an assigned IEC or IEEE symbol number. Any separately listed Autodesk code is a verified vendor block name.
