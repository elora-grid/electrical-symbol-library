# Flashing indicator lamp

A flashing indicator lamp provides a documented intermittent visual indication.

## What it represents

A flashing indicator lamp provides a documented intermittent visual indication. The flash-generation function may be internal or separately controlled and should be identified.

## How to read it

- Trace whether the flashing signal originates in the lamp assembly or the controller.
- The preview is an original explanation of this function. Match the actual drawing convention to its legend and the selected equipment documentation.

## Drawing checklist

- State supply rating
- Define indication meaning
- Reference flash-control source

## Important distinction

A flashing indication is different from an ordinary steady lamp driven by an unlabelled intermittent signal.
