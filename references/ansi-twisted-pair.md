# ANSI/IEEE twisted pair symbol

IEEE-oriented representation of two conductors twisted together, used to identify noise-rejecting signal pairs.

[Canonical reference](https://eloragrid.ai/symbols/ansi-twisted-pair) · [Structured record](../entries/ansi-twisted-pair.json) · [All references](README.md)

Updated: 2026-10-28. Drawing use: Schematic. Reference families: IEEE / ANSI.

Graphical convention: IEEE / ANSI. Twisted pair crossing form.

## What it represents

IEEE-style schematics show a twisted pair with the two conductor lines crossing repeatedly over a short length. It identifies conductors that must be kept as a pair in one cable, such as differential signal lines, current transformer secondary pairs run in instrument cables, or communication buses.
The illustration here explains the convention and is not the IEEE graphic. The twist mark does not imply a shield. When a pair is also shielded the drawing should add the shield enclosure; when it is part of a multipair cable, the pair number should be given.

## How to read it

- Keep both conductors of the pair on the same circuit.
- Look for a separate shield mark if a shield exists.

## Drawing checklist

- Identify pair number within the cable.
- Add a shield mark only if shielded.
- Route pair conductors together on wiring diagrams.

## Important distinction

A twisted pair is twisted only; a shielded conductor has a screen and may not be twisted.
