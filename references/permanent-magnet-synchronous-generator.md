# Permanent-magnet synchronous generator

A permanent-magnet synchronous generator provides an AC source using a permanent magnetic excitation system.

[Canonical reference](https://eloragrid.ai/symbols/permanent-magnet-synchronous-generator) · [Structured record](../entries/permanent-magnet-synchronous-generator.json) · [All references](README.md)

Updated: 2026-10-27. Drawing use: SLD, Schematic. Reference families: IEC, Manufacturer.

## What it represents

A permanent-magnet synchronous generator provides an AC source using a permanent magnetic excitation system. Any converter between this source and the AC network must be shown separately.

## How to read it

- Distinguish machine output from the downstream converter's controlled network output.
- The preview is an original explanation of this function. Match the actual drawing convention to its legend and the selected equipment documentation.

## Drawing checklist

- State machine rating
- Identify winding terminals
- Reference converter interface

## Important distinction

Permanent-magnet excitation does not mean direct grid connection is appropriate for every machine.
