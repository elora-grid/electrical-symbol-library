## What it represents

This reference locates two-network voltage measurement selector in Autodesk's IEEE-oriented miscellaneous switches family. This representation distinguishes voltage selection between two three-phase networks. The measurement is selected from more than one network or bus system. Both source identities must remain visible so that a reading is not attributed to the wrong supply. The public library uses HSW1S93 for its horizontal representation; this is a vendor block name, not an IEEE standards symbol number.
Read the operating mechanism and the contact reference state together. Cross-reference every associated contact to the same device and show which movement, signal or reset changes its condition; the symbol alone does not establish the complete switching sequence.
Tag the two measurement sources and provide a position table with each voltage pair. This selector does not create a load-supply transfer arrangement between the networks. Identify both sources and each selectable measurement connection. Measurement selection between networks is not an automatic source-transfer power switch. The linked functional counterpart explains the same operating role in its own drawing context; agreement of every detailed convention mark is not asserted.
