# Star winding connection

A star winding joins one end of each phase winding at a common point.

[Canonical reference](https://eloragrid.ai/symbols/star-winding-connection) · [Structured record](../entries/star-winding-connection.json) · [All references](README.md)

Updated: 2026-10-27. Drawing use: SLD, Schematic. Reference families: IEC, Manufacturer.

## What it represents

A star winding joins one end of each phase winding at a common point. The external phase terminals and the common point determine the winding topology.

## How to read it

- Check whether the common point is internal or brought out as a neutral terminal.
- The preview is an original explanation of this function. Match the actual drawing convention to its legend and the selected equipment documentation.

## Drawing checklist

- Show phase winding ends
- Identify common point
- Reference terminal designations

## Important distinction

A drawn star point does not mean that it is accessible for external connection.
