## What it represents

A logic element whose output is true when all stated positive-logic inputs are true.
On a schematic, identify the input signal polarity and the required simultaneous conditions and trace the gate output and its destination. Keep the component tag and signal/reference names consistent across the control drawing, terminal schedule and device documentation.
An AND gate combines logical conditions; it does not specify relay-contact current capacity or a safety integrity level.
Terminal letters describe electrical roles, not package pin numbers. Check the selected public datasheet for the actual pin assignment, polarity and any internally connected terminals before completing the drawing.
