## What it represents

Controls engagement of the turning gear used to rotate a large machine at low speed.
In a drafting package, connect this reference to the turning-gear mechanism and speed/interlock signals. The associated drawing should trace the engagement actuator and proof-of-position circuit; the number identifies the role and does not specify the terminal arrangement, ratings or operating settings.
This designation is useful when reading machine and legacy control drawings. Retain the documented function on an existing drawing and consult the original equipment manual before assigning it to a new design.
