# Multi-tube fluorescent luminaire plan mark

Plan mark for a linear luminaire with several tubes, shown as parallel lines between common end bars.

[Canonical reference](https://eloragrid.ai/symbols/iec-multi-lamp-fluorescent-luminaire) · [Structured record](../entries/iec-multi-lamp-fluorescent-luminaire.json) · [All references](README.md)

Updated: 2026-10-28. Drawing use: GA. Reference families: IEC.

Graphical convention: IEC. Multi-lamp fluorescent luminaire.

## What it represents

Multi-lamp linear luminaires, such as twin or triple tube troffers, are drawn with parallel lines between end bars, one line per lamp. Alternatively a single line with a numeral is used. The form helps lighting designers check that luminaire output matches the calculation.
Modular recessed fittings in a suspended ceiling grid are often drawn as a rectangle the size of the tile with internal lines for lamps. The plan then serves for coordinating ceiling tiles, sprinkler heads and diffusers. Line count does not show lamp wattage or ballast type. Read the schedule.

## How to read it

- Count the lines or read the numeral.
- Check grid coordination for recessed versions.

## Drawing checklist

- State number of lamps.
- Tag fixture type.
- Coordinate with ceiling services.

## Important distinction

The single-line form shows one lamp; parallel lines show multi-lamp fittings.

## Facts

- Graphic form: Parallel lines between end bars
- Count: One line per lamp
