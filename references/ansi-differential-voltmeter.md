# ANSI/IEEE differential voltmeter symbol

IEEE-library differential voltmeter form reading the difference between two voltages, for example across a synchronising point.

[Canonical reference](https://eloragrid.ai/symbols/ansi-differential-voltmeter) · [Structured record](../entries/ansi-differential-voltmeter.json) · [All references](README.md)

Updated: 2026-10-28. Drawing use: Schematic. Reference families: IEEE / ANSI, Manufacturer.

Graphical convention: IEEE / ANSI. Autodesk IEEE-oriented Instrumentation and Sensors form: Differential Voltmeter.

## What it represents

A differential voltmeter reads the difference between two applied voltages rather than either voltage alone. In synchronising panels it is wired between the incoming and running VT secondaries so the operator can see when the voltage difference is small enough to close the breaker.
The symbol does not show whether both inputs come from the same phase, or whether VT ratios are matched. If the two VTs have different ratios or phase shifts through a transformer, the reading is meaningless unless interposing correction is drawn.

## How to read it

- Confirm both inputs are taken from the same phase pair.
- Check the VT ratios on both sides of the closing point.

## Drawing checklist

- Identify both voltage sources
- Show phase reference
- Note any ratio or angle correction

## Important distinction

A differential voltmeter shows the difference between two voltages; a double voltmeter shows both voltages on separate scales.
