# AC circuit breaker

The device-function number identifying an AC circuit breaker.

[Canonical reference](https://eloragrid.ai/protection-functions/52-ac-circuit-breaker) · [Structured record](../entries/52-ac-circuit-breaker.json) · [All references](README.md)

Updated: 2026-10-27. Drawing use: SLD, Schematic. Reference families: IEEE / ANSI.

## What it represents

Device function number 52 identifies an AC circuit breaker in the power-system device-function convention. It can appear in equipment identification, control references or a protection drawing, but it remains distinct from the graphical symbol and product specification.
On a power drawing, keep this function reference connected to the selected equipment and its complete designation. A multifunction relay can implement several numbered functions. This entry explains the reference; it supplies no settings or commissioning procedure.

## How to read it

- Associate the number with the intended breaker equipment reference.
- Read auxiliary-contact and control designations from the applicable documentation.

## Drawing checklist

- Link the breaker equipment tag.
- Cross-reference close and trip circuits.
- Reference auxiliary contacts and device documentation.

## Important distinction

The number 52 identifies a device function. It is not an IEC graphical-symbol identifier, breaker current rating or manufacturer model.

## Facts

- ANSI / IEEE function number: 52
- Equipment implementation: Consult the selected device manual
- Suffix interpretation: Application and manufacturer documentation
