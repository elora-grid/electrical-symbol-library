## What it represents

This reference locates current window monitoring relay in Autodesk's IEEE-oriented current protection relays family. A current-window relay supervises both minimum and maximum current conditions. Its drawing links the measured circuit to separate or combined outputs according to the actual relay configuration. The public library uses HCR1F27 for its horizontal representation; this is a vendor block name, not an IEEE standards symbol number.
