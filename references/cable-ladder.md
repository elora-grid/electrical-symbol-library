# Cable ladder / tray

A generic route object connecting cable-support layout to the selected system.

[Canonical reference](https://eloragrid.ai/objects/cable-ladder) · [Structured record](../entries/cable-ladder.json) · [All references](README.md)

Updated: 2026-10-27. Drawing use: GA. Reference families: Manufacturer.

## What it represents

A cable-support route identifies where a selected tray or ladder system carries cables through an arrangement. Straight lengths, bends, fittings and supports belong to a manufacturer system, and their dimensions and capabilities should be documented for that selection.

## How to read it

- Read the route and changes of direction together with support and fitting information.
- Distinguish cable-routing space from the physical support-system envelope.

## Drawing checklist

- Reference the selected support system.
- Identify route levels, fittings and interfaces.
- Link the cable and support documentation.

## Important distinction

A drawn route does not establish support spacing, loading capability or installation compliance.
