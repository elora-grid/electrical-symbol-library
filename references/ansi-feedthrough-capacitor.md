## What it represents

The feedthrough capacitor form combines a through conductor with a documented capacitive filtering connection. Its circuit reader must distinguish the through-current path from the return or case connection serving the filtering function.
This is a convention-specific lookup based on the publisher's IEEE-labelled preview. The geometry here is independently drawn to explain the connection or operation; it is not a certified reproduction of the standard graphic.

## How to read it

- Follow the through conductor and shunt return as different paths.
- Read the selected library and the project legend together. A vendor block identifier is meaningful within its named library and is not a universal standard-symbol code.

## Drawing checklist

- Identify filtered conductor
- Show return/case connection
- Reference component ratings

## Important distinction

A feedthrough capacitor is a filtering element, not a detachable feed-through terminal.
