# Loss-of-voltage monitoring relay

A loss-of-voltage relay changes its output for a documented absence-of-voltage condition.

[Canonical reference](https://eloragrid.ai/symbols/loss-of-voltage-monitoring-relay) · [Structured record](../entries/loss-of-voltage-monitoring-relay.json) · [All references](README.md)

Updated: 2026-10-27. Drawing use: SLD, Schematic. Reference families: Manufacturer.

## What it represents

A loss-of-voltage relay changes its output for a documented absence-of-voltage condition. Schematics distinguish measurement failure, actual source loss and auxiliary-supply loss where the design requires them.

## How to read it

- Trace the monitored voltage independently from relay auxiliary power.
- The preview is an original explanation of this function. Match the actual drawing convention to its legend and the selected equipment documentation.

## Drawing checklist

- Identify monitored source
- State loss criterion
- Show output and supply-loss behaviour

## Important distinction

Loss-of-voltage indication is not necessarily the same function as breaker undervoltage release.
