## What it represents

This reference locates phase-to-neutral voltmeter selector in Autodesk's IEEE-oriented miscellaneous switches family. This representation identifies selection among phase-to-neutral voltage measurement connections. The meter is connected to the selected phase relative to the documented neutral or reference point. That connection differs from measuring between two phase conductors. The public library uses HSW1S91 for its horizontal representation; this is a vendor block name, not an IEEE standards symbol number.
Read the operating mechanism and the contact reference state together. Cross-reference every associated contact to the same device and show which movement, signal or reset changes its condition; the symbol alone does not establish the complete switching sequence.
Show the reference terminal and each selectable measurement path. The position table should make clear which reading the operator receives at each position. Show the neutral/reference connection and each selected phase in the position table. Phase-to-neutral and phase-to-phase measurements have different connection paths. The linked functional counterpart explains the same operating role in its own drawing context; agreement of every detailed convention mark is not asserted.
