# Current window monitoring relay

A current-window relay supervises both minimum and maximum current conditions.

Updated: 2026-10-27. Drawing use: SLD, Schematic. Reference families: Manufacturer.

## What it represents

A current-window relay supervises both minimum and maximum current conditions. Its drawing links the measured circuit to separate or combined outputs according to the actual relay configuration.

## How to read it

- Identify the permitted current band and any start-up inhibition.
- The preview is an original explanation of this function. Match the actual drawing convention to its legend and the selected equipment documentation.

## Drawing checklist

- State both thresholds
- Reference timing/inhibit logic
- Show output assignment

## Important distinction

A current window is a range-supervision function, not a measurement accuracy band.
