## What it represents

A positive-logic element whose output is true when at least one input is true.
On a schematic, identify the input signal meanings and the inclusive-OR convention and trace the combined permissive or alarm output. Keep the component tag and signal/reference names consistent across the control drawing, terminal schedule and device documentation.
Inclusive OR differs from XOR: OR remains true when both inputs are true.
Terminal letters describe electrical roles, not package pin numbers. Check the selected public datasheet for the actual pin assignment, polarity and any internally connected terminals before completing the drawing.
