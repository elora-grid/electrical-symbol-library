# Unit sequence switch

Selects or determines the order in which multiple units enter an operating sequence.

[Canonical reference](https://eloragrid.ai/protection-functions/10-unit-sequence-switch) · [Structured record](../entries/10-unit-sequence-switch.json) · [All references](README.md)

Updated: 2026-10-27. Drawing use: SLD, Schematic. Reference families: IEEE / ANSI.

## What it represents

Selects or determines the order in which multiple units enter an operating sequence.
In a drafting package, connect this reference to the selected unit order and selector positions. The associated drawing should trace the unit-specific start-permission circuits; the number identifies the role and does not specify the terminal arrangement, ratings or operating settings.

## How to read it

- Identify the selected unit order and selector positions.
- Trace the unit-specific start-permission circuits.

## Drawing checklist

- Label the selected unit order and selector positions.
- Cross-reference the unit-specific start-permission circuits.
- Identify the device tag, manual revision and logic drawing that define this implementation.

## Important distinction

Unit ordering differs from device 34, which sequences the operations inside a unit or system.

## Facts

- ANSI / IEEE function number: 10
- Drawing context: The selected unit order and selector positions
- Application scope: Protection or apparatus-control role; exact implementation is defined by the equipment documentation.
