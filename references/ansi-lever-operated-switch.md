## What it represents

This reference locates lever-operated switch in Autodesk's IEEE-oriented miscellaneous switches family. A lever-operated switch changes contact state through a manually operated lever. The lever's travel, stable positions and return behaviour are part of the operator schedule. The public library uses HPB11LS for its horizontal representation; this is a vendor block name, not an IEEE standards symbol number.
Read the operating mechanism and the contact reference state together. Cross-reference every associated contact to the same device and show which movement, signal or reset changes its condition; the symbol alone does not establish the complete switching sequence.
Compare the contact schedule to each lever position. Lever actuation is different from a lever limit switch driven by equipment movement. The linked functional counterpart explains the same operating role in its own drawing context; agreement of every detailed convention mark is not asserted.
