# ANSI/IEEE current transformer with conductor indication symbol

IEEE-library CT form that shows the primary conductor passing through the core, as with window and bar-type CTs.

[Canonical reference](https://eloragrid.ai/symbols/ansi-current-transformer-with-primary-conductor-indication) · [Structured record](../entries/ansi-current-transformer-with-primary-conductor-indication.json) · [All references](README.md)

Updated: 2026-10-28. Drawing use: SLD, Schematic. Reference families: IEEE / ANSI, Manufacturer.

Graphical convention: IEEE / ANSI. Autodesk IEEE-oriented Current Transformers form: With Conductor Indication.

## What it represents

This CT form draws the primary conductor explicitly passing through the transformer core. It suits window, bar and bushing CTs where the primary is the main circuit conductor itself, and it helps the reader see which conductor, and how many passes, the CT encloses.
The conductor indication does not give ratio, accuracy class or burden. If the primary passes the window more than once, the effective ratio changes, so turns through the window must be noted beside the symbol.

## How to read it

- Count primary passes through the window.
- Check polarity marks against the primary current direction.

## Drawing checklist

- State ratio and class
- Show polarity marks
- Note primary passes

## Important distinction

The conductor-indication form shows the enclosed primary; the plain CT form represents the CT without showing how the primary is arranged.
