# Zener diode

A Zener diode is a semiconductor component intended for a documented reverse-breakdown operating function.

## What it represents

A Zener diode is a semiconductor component intended for a documented reverse-breakdown operating function. The schematic identifies its polarity and the associated current-limiting or bias circuit.

## Drawing checklist

- State rated breakdown voltage
- Show polarity
- Reference current-limiting network

## Important distinction

A Zener diode's specified breakdown function differs from an ordinary rectifier diode's intended service.
