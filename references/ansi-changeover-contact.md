## What it represents

The Form C relay contact representation links a common connection to alternative contact paths. The reader must identify common, normally closed and normally open terminals, with transition timing specified separately where overlap matters.
This is a convention-specific lookup based on the publisher's IEEE-labelled preview. The geometry here is independently drawn to explain the connection or operation; it is not a certified reproduction of the standard graphic.

## How to read it

- Trace the common terminal to each throw using the stated reference state.
- Read the selected library and the project legend together. A vendor block identifier is meaningful within its named library and is not a universal standard-symbol code.

## Drawing checklist

- Label common/NO/NC
- Identify parent relay
- Reference transfer sequence

## Important distinction

Form C identifies a changeover contact arrangement; it does not by itself establish make-before-break behaviour.
