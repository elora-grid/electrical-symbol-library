## What it represents

The on-delay NC contact form specifically describes delayed opening from its reference closed state. The controlled path remains continuous while the specified delay runs, so the timer tag and timing condition are essential circuit-reading information.
This is a convention-specific lookup based on the publisher's IEEE-labelled preview. The geometry here is independently drawn to explain the connection or operation; it is not a certified reproduction of the standard graphic.

## How to read it

- Trace the permissive or command during the delay interval.
- Read the selected library and the project legend together. A vendor block identifier is meaningful within its named library and is not a universal standard-symbol code.

## Drawing checklist

- Identify timer tag
- State opening delay
- Reference reset condition

## Important distinction

Normally closed describes the initial contact state while on-delay identifies the specified operating transition.
