## What it represents

The off-delay NC contact form identifies instant opening on operation and a delayed return to the documented closed state. The circuit remains interrupted during the specified release interval, with supply-loss handling defined by the timer product.
This is a convention-specific lookup based on the publisher's IEEE-labelled preview. The geometry here is independently drawn to explain the connection or operation; it is not a certified reproduction of the standard graphic.

## How to read it

- Identify which transition is delayed rather than assigning delay to both directions.
- Read the selected library and the project legend together. A vendor block identifier is meaningful within its named library and is not a universal standard-symbol code.

## Drawing checklist

- Match timer reference
- State return-to-closed delay
- Reference trigger and supply conditions

## Important distinction

Contact polarity and timing direction are independent aspects of the output definition.
