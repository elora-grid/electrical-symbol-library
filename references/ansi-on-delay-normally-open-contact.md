## What it represents

The on-delay NO contact form specifically describes a delayed-closing transition. Its timer reference supplies the initiating condition and interval, while the unoperated contact remains open; release or reset behaviour comes from the documented timing chart.
This is a convention-specific lookup based on the publisher's IEEE-labelled preview. The geometry here is independently drawn to explain the connection or operation; it is not a certified reproduction of the standard graphic.

## How to read it

- Separate the delay-close transition from the contact's return action.
- Read the selected library and the project legend together. A vendor block identifier is meaningful within its named library and is not a universal standard-symbol code.

## Drawing checklist

- Link timer element
- State closing delay
- Reference reset behaviour

## Important distinction

A timed output contact differs from the timer coil or trigger that initiates its timing.
