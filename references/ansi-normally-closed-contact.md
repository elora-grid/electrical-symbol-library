## What it represents

The normally-closed relay contact form identifies a conducting path in its documented unoperated condition. The operating action changes that path; it does not tell the reader whether the controlled equipment is normally running or stopped.
This is a convention-specific lookup based on the publisher's IEEE-labelled preview. The geometry here is independently drawn to explain the connection or operation; it is not a certified reproduction of the standard graphic.

## How to read it

- Evaluate the controlled circuit in both reference and operated states.
- Read the selected library and the project legend together. A vendor block identifier is meaningful within its named library and is not a universal standard-symbol code.

## Drawing checklist

- State reference condition
- Identify contact terminals
- Link operating device

## Important distinction

A closed reference contact and a closed circuit breaker describe different devices and circuit duties.
