# Generator package

A generic generating-package envelope linked to official equipment and installation drawings.

Updated: 2026-10-27. Drawing use: GA. Reference families: Manufacturer.

## What it represents

A generator package can include the electrical machine, prime mover and equipment defined by its supply scope. Its enclosure and installation interfaces depend on the selected package. The GA must therefore reference the actual product and project equipment scope.

## How to read it

- Identify which accessories are included in the represented package.
- Connect the physical package reference to the electrical source on the SLD.

## Drawing checklist

- Reference the manufacturer package GA.
- Identify electrical and other installation interfaces.
- Link the generator and control schedules.

## Important distinction

A generic generator outline does not define ventilation, exhaust, fuel, acoustic performance or service access requirements.
