# Temperature control device

Controls heating, cooling or another process action using a temperature input.

## What it represents

Controls heating, cooling or another process action using a temperature input.
In a drafting package, connect this reference to the temperature sensor and controlled equipment. The associated drawing should trace the heating, cooling or regulating output; the number identifies the role and does not specify the terminal arrangement, ratings or operating settings.

## How to read it

- Identify the temperature sensor and controlled equipment.
- Trace the heating, cooling or regulating output.

## Drawing checklist

- Label the temperature sensor and controlled equipment.
- Cross-reference the heating, cooling or regulating output.
- Identify the device tag, manual revision and logic drawing that define this implementation.

## Important distinction

Temperature control maintains a process condition; thermal protection 49 addresses the protected equipment's thermal duty.

## Facts

- ANSI / IEEE function number: 23
- Drawing context: The temperature sensor and controlled equipment
- Application scope: Protection or apparatus-control role; exact implementation is defined by the equipment documentation.
