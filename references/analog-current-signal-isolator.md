# Analog current signal isolator

## What it represents

A current signal isolator transfers a documented analog current input to an output while providing the specified electrical separation. Signal input, output and auxiliary supply are distinct terminal groups.

## How to read it

- Determine active and passive current-loop roles at both interfaces.
- The preview is an original explanation of this function. Match the actual drawing convention to its legend and the selected equipment documentation.

## Drawing checklist

- State input/output range
- Show separate commons
- Reference supply and isolation rating

## Important distinction

Signal isolation is different from changing the power-system voltage with a transformer.
