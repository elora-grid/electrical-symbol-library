# PLC analog input

## What it represents

A PLC analog input measures a documented voltage, current or sensor quantity. Its signal range, common and any shield/earth connection require explicit wiring information.

## How to read it

- Identify the selected channel mode before interpreting its terminals.
- The preview is an original explanation of this function. Match the actual drawing convention to its legend and the selected equipment documentation.

## Drawing checklist

- State signal type/range
- Show signal common and shield
- Reference channel configuration

## Important distinction

Analog measurement carries a range of values; a digital input reads a discrete state.
