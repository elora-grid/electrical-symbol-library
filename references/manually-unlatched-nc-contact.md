# Manually unlatched NC contact

A manually unlatched NC contact has a mechanical retained state and a documented manual release.

Updated: 2026-10-27. Drawing use: Schematic. Reference families: IEC, Manufacturer.

## What it represents

A manually unlatched NC contact has a mechanical retained state and a documented manual release. Its reference state is closed but the retained operated position must be stated.

## How to read it

- Confirm which contact position the mechanism retains.

## Drawing checklist

- State reference and retained states
- Identify manual release
- Link associated device

## Important distinction

A mechanical retention marker must not be confused with a delayed-return timer marker.
