## What it represents

The maintained NC contact form adds a retention characteristic to the reference closed contact. Analysing a control sequence requires both the initial continuity and the stated retained operating condition.
This is a convention-specific lookup based on the publisher's IEEE-labelled preview. The geometry here is independently drawn to explain the connection or operation; it is not a certified reproduction of the standard graphic.

## How to read it

- Evaluate the next cycle only after identifying reset or return.
- Read the selected library and the project legend together. A vendor block identifier is meaningful within its named library and is not a universal standard-symbol code.

## Drawing checklist

- State reference state
- Identify retained position
- Link reset mechanism

## Important distinction

A maintained NC contact is not an off-delay contact unless timing is separately specified.
