## What it represents

This reference locates manually released latching device in Autodesk's IEEE-oriented mechanical controls, latching device family. This qualifier identifies release of a latching mechanism by manual action. The retained mechanism is released through a documented manual action. Resetting the mechanism and removing electrical supply can be different events. The public library uses Q1020604 for its horizontal representation; this is a vendor block name, not an IEEE standards symbol number.
Read the operating mechanism and the contact reference state together. Cross-reference every associated contact to the same device and show which movement, signal or reset changes its condition; the symbol alone does not establish the complete switching sequence.
Show the manual release and the resulting position relationship. Where the latch also reports status, identify that feedback as a separate contact or sensor interface. Show the reset or release device and the resulting rest condition. Manual unlatching differs from de-energising an ordinary relay coil.
