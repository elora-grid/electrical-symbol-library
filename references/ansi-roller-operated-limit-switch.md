## What it represents

The roller limit-switch form identifies a mechanical roller actuator associated with the contact function. The electrical drawing records the signal path; the equipment detail determines the actual motion, roller location and allowable travel.
This is a convention-specific lookup based on the publisher's IEEE-labelled preview. The geometry here is independently drawn to explain the connection or operation; it is not a certified reproduction of the standard graphic.

## How to read it

- Read the contact action against the roller's documented motion.
- Read the selected library and the project legend together. A vendor block identifier is meaningful within its named library and is not a universal standard-symbol code.

## Drawing checklist

- Identify roller/actuator detail
- State contact behaviour
- Reference travel/overtravel limits

## Important distinction

A roller actuator is a mechanical input, not an inductive proximity sensing element.
