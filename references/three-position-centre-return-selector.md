# Three-position centre-return selector

A centre-return selector returns from both outer positions to its documented central rest position.

Updated: 2026-10-27. Drawing use: Schematic. Reference families: IEC, Manufacturer.

## What it represents

A centre-return selector returns from both outer positions to its documented central rest position. It can issue opposite momentary commands without retaining either outer position.

## How to read it

- The centre rest position still needs a defined contact state.
- The preview is an original explanation of this function. Match the actual drawing convention to its legend and the selected equipment documentation.

## Drawing checklist

- Name centre condition
- Identify both momentary commands
- State contact schedule

## Important distinction

Centre return describes the mechanism; centre off describes a contact condition.
