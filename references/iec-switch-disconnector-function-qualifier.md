# Switch-disconnector function qualifier

This qualifier identifies combined switching and isolation in the associated representation.

Updated: 2026-10-27. Drawing use: SLD, Schematic. Reference families: IEC, Manufacturer.

Graphical convention: IEC. Switch-disconnector function qualifier.

## What it represents

This qualifier identifies combined switching and isolation in the associated representation. The combined function tells the reader that switching and isolation belong to the associated device representation. It does not add an overcurrent trip function.
When the SLD is expanded into a control schematic, retain the device tag and show any auxiliary contacts or operating mechanism separately. Protective devices elsewhere in the circuit remain separate items.

## How to read it

- Read it with the complete power device and its operating-state information.
- Switch-disconnector duty is different from automatic circuit-breaker interruption.
