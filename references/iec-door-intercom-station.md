# Door intercom station symbol

Plan symbol for an intercom door station with speaker and microphone, used for visitor entry.

[Canonical reference](https://eloragrid.ai/symbols/iec-door-intercom-station) · [Structured record](../entries/iec-door-intercom-station.json) · [All references](README.md)

Updated: 2026-10-28. Drawing use: GA. Reference families: IEC.

Graphical convention: IEC. Intercom station.

## What it represents

Door intercom stations combine a loudspeaker, microphone and call button, and sometimes a camera, at a building entry. Plans draw a box with combined loudspeaker and microphone marks, tagged IC or DS, beside the door.
The station links to indoor answering units and often to an electric door release. The plan should show this link so the installer runs the right cabling. The symbol does not show whether the system is two-wire, IP or audio-only.

## How to read it

- Find the linked answering units.
- Check for door release interface.

## Drawing checklist

- State system type.
- Show answering units.
- Show door release.

## Important distinction

A combined loudspeaker and microphone symbol is a component; this marks a complete entry station.

## Facts

- Elements: Speaker, microphone, call button
- Interfaces: Answering units and door release
- Exact standard graphic: Not reproduced here; confirm the form against IEC 60617 and the project legend
