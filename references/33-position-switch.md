# Position switch

Changes an electrical indication when a mechanism reaches a defined physical position.

[Canonical reference](https://eloragrid.ai/protection-functions/33-position-switch) · [Structured record](../entries/33-position-switch.json) · [All references](README.md)

Updated: 2026-10-27. Drawing use: SLD, Schematic. Reference families: IEEE / ANSI.

## What it represents

Changes an electrical indication when a mechanism reaches a defined physical position.
In a drafting package, connect this reference to the mechanism position and contact's normal-state convention. The associated drawing should trace the position indication and permissive circuits; the number identifies the role and does not specify the terminal arrangement, ratings or operating settings.

## How to read it

- Identify the mechanism position and contact's normal-state convention.
- Trace the position indication and permissive circuits.

## Drawing checklist

- Label the mechanism position and contact's normal-state convention.
- Cross-reference the position indication and permissive circuits.
- Identify the device tag, manual revision and logic drawing that define this implementation.

## Important distinction

A position switch identifies position, not necessarily that an electrically commanded operation has succeeded.

## Facts

- ANSI / IEEE function number: 33
- Drawing context: The mechanism position and contact's normal-state convention
- Application scope: Protection or apparatus-control role; exact implementation is defined by the equipment documentation.
