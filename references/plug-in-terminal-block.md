# Plug-in terminal block

A plug-in terminal allows a documented terminal circuit to be disconnected through a removable mating part.

## What it represents

A plug-in terminal allows a documented terminal circuit to be disconnected through a removable mating part. The schematic and terminal plan identify both fixed and removable sides where necessary.

## How to read it

- Keep the mating connector identity with the terminal path.
- The preview is an original explanation of this function. Match the actual drawing convention to its legend and the selected equipment documentation.

## Drawing checklist

- Name fixed and plug sides
- State pole/pin identifiers
- Reference normal connected state

## Important distinction

Plug-in construction describes a removable connection, not a fuse or isolation rating.
