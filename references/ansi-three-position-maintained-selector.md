## What it represents

The three-position maintained selector form provides three stable choices in the named library. Each associated contact is interpreted through the complete position table, with a shared tag tying the operator and contact blocks together.
This is a convention-specific lookup based on the publisher's IEEE-labelled preview. The geometry here is independently drawn to explain the connection or operation; it is not a certified reproduction of the standard graphic.

## How to read it

- Check all three positions rather than treating the middle as an assumed off state.
- Read the selected library and the project legend together. A vendor block identifier is meaningful within its named library and is not a universal standard-symbol code.

## Drawing checklist

- Label positions
- State every contact condition
- Link common operator

## Important distinction

A stable centre position and a spring-return centre position describe different mechanisms.
