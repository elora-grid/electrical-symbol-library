## What it represents

This reference locates three-wire inductive proximity switch in Autodesk's IEEE-oriented inductive switches family. A three-wire inductive proximity switch uses separate supply, common and output conductors. Its output polarity and load connection must match the receiving input module. The public library uses HPX11IN3 for its horizontal representation; this is a vendor block name, not an IEEE standards symbol number.
