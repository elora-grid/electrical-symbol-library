# Weatherproof socket outlet

Plan mark for an outdoor or wet-area socket outlet with a protective enclosure, usually tagged with its IP rating.

[Canonical reference](https://eloragrid.ai/symbols/iec-weatherproof-socket-outlet) · [Structured record](../entries/iec-weatherproof-socket-outlet.json) · [All references](README.md)

Updated: 2026-10-28. Drawing use: GA. Reference families: IEC.

Graphical convention: IEC. Weatherproof socket outlet.

## What it represents

Weatherproof outlets are placed on external walls, in wash-down areas, car parks and roof plant. The plan symbol uses the normal outlet form with an IP or WP tag, and some legends add a small enclosure line around the outlet to show the hinged cover.
The tag matters to the installer because it decides the accessory family, gland type and whether the cover must keep its rating with a plug inserted. Outdoor outlets also usually require residual-current protection, so the reader should look for the RCD indication or the circuit schedule note.
The symbol does not state the actual IP code unless the number is written. WP alone is a project shorthand; the specification should fix the numeric rating.

## How to read it

- Look for an IP number, not just WP or EXT text.
- Check whether the outlet is also shown as residual-current protected.

## Drawing checklist

- State the IP code required with a plug inserted where relevant.
- Confirm residual-current protection for the circuit.
- Show mounting height above finished ground.

## Important distinction

An interior outlet and a weatherproof outlet can share the same base form; only the enclosure tag or outline distinguishes them.

## Facts

- Typical tag: IP rating such as IP56 or IP66
- Location: External walls, wet areas, roof plant
- Exact standard graphic: Not reproduced here; confirm the form against IEC 60617 and the project legend
