# Bearing protective device

Supervises an abnormal condition at a machine bearing, often using temperature or mechanical sensing.

Updated: 2026-10-27. Drawing use: SLD, Schematic. Reference families: IEEE / ANSI.

## What it represents

Supervises an abnormal condition at a machine bearing, often using temperature or mechanical sensing.
In a drafting package, connect this reference to the bearing identity and sensor type. The associated drawing should trace the bearing alarm or machine trip destination; the number identifies the role and does not specify the terminal arrangement, ratings or operating settings.

## How to read it

- Identify the bearing identity and sensor type.
- Trace the bearing alarm or machine trip destination.

## Drawing checklist

- Label the bearing identity and sensor type.
- Cross-reference the bearing alarm or machine trip destination.
- Identify the device tag, manual revision and logic drawing that define this implementation.

## Important distinction

Bearing protection is tied to a monitored bearing; winding thermal protection addresses a different equipment location.

## Facts

- ANSI / IEEE function number: 38
- Drawing context: The bearing identity and sensor type
- Application scope: Protection or apparatus-control role; exact implementation is defined by the equipment documentation.
