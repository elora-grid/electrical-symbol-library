# AC-to-DC power supply

An AC/DC power supply converts a documented AC input to a DC output for control or auxiliary circuits.

## What it represents

An AC/DC power supply converts a documented AC input to a DC output for control or auxiliary circuits. Its input protection, DC common and any PE connection are shown separately.

## How to read it

- Identify the DC output polarity and any intentional connection to earth.
- The preview is an original explanation of this function. Match the actual drawing convention to its legend and the selected equipment documentation.

## Drawing checklist

- State AC input range
- State DC output rating
- Show input protection and PE

## Important distinction

A regulated power supply includes functions beyond a bridge rectifier alone.
