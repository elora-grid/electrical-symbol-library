# Bidirectional breakdown diode

A bidirectional breakdown diode provides a documented voltage-limiting semiconductor path in both polarities.

## What it represents

A bidirectional breakdown diode provides a documented voltage-limiting semiconductor path in both polarities. Its working voltage and surge characteristics determine the protective application.

## How to read it

- Read working-voltage and breakdown specifications separately.
- The preview is an original explanation of this function. Match the actual drawing convention to its legend and the selected equipment documentation.

## Drawing checklist

- Identify protected nodes
- State working-voltage rating
- Reference surge capability

## Important distinction

Bidirectional protection does not make the component a controllable power switch.
