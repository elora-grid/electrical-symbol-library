## What it represents

The non-auto-return NO pushbutton form identifies a retained operator condition. The control input can remain active after the user's initiating action, so the documented release mechanism is part of the drawing's functional meaning.
This is a convention-specific lookup based on the publisher's IEEE-labelled preview. The geometry here is independently drawn to explain the connection or operation; it is not a certified reproduction of the standard graphic.

## How to read it

- Find how the button returns before evaluating a repeated command.
- Read the selected library and the project legend together. A vendor block identifier is meaningful within its named library and is not a universal standard-symbol code.

## Drawing checklist

- State retained position
- Identify release method
- Reference contact terminals

## Important distinction

Mechanical retention is different from a controller remembering a momentary input.
