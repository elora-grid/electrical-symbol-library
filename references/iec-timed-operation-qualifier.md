## What it represents

A timed-operation qualifier identifies operation influenced by the documented timing function. A timing relationship describes when an action follows an initiating event. It does not decide whether the timing continues after the input disappears or how the function resets.
Document the input transition, the timed output and the intended timing mode. The main contact or actuator representation still supplies the resulting state.

## How to read it

- State the trigger, timing mode and reset condition separately.
- A generic timing indication does not distinguish on-delay, off-delay or pulse operation.
