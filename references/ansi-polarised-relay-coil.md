## What it represents

The polarised-relay form indicates a documented sensitivity to input polarity or direction. The schematic's terminal labels and polarity reference must remain intact when the element is rearranged, because page orientation does not establish electrical polarity.
This is a convention-specific lookup based on the publisher's IEEE-labelled preview. The geometry here is independently drawn to explain the connection or operation; it is not a certified reproduction of the standard graphic.

## How to read it

- Use terminal data to determine the operating polarity.
- Read the selected library and the project legend together. A vendor block identifier is meaningful within its named library and is not a universal standard-symbol code.

## Drawing checklist

- Mark input polarity
- State operating range
- Reference output behaviour

## Important distinction

Polarised operation differs from the polarity restriction introduced solely by a suppression diode on an ordinary relay coil.
