# Removable earth test link

A removable link between the main earthing terminal and the earth electrode, opened to measure electrode resistance.

[Canonical reference](https://eloragrid.ai/symbols/iec-removable-earth-test-link) · [Structured record](../entries/iec-removable-earth-test-link.json) · [All references](README.md)

Updated: 2026-10-28. Drawing use: SLD, Schematic. Reference families: IEC.

Graphical convention: IEC. Removable earthing link.

## What it represents

The earth test link sits in the earthing conductor between the main earthing terminal and the earth electrode. Removing it isolates the electrode so its resistance can be measured on its own. Installation guidance describes it as part of the earthing arrangement at the main earthing terminal.
The link must be replaced after testing, and the installation is not adequately earthed while it is open. The symbol does not tell you whether other earth paths exist in parallel, such as the supply earth, which would affect test readings and safety during the test.

## How to read it

- Check for parallel earth paths that affect electrode testing.
- Confirm the link is restored after testing.

## Drawing checklist

- Show the link between MET and electrode.
- Label it for testing.
- Note any parallel earth paths.

## Important distinction

An earth test link is removed only for electrode testing; a neutral-to-earth link bonds neutral and earth in service.
