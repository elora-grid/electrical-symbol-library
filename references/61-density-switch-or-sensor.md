# Density switch or sensor

Monitors the density of a medium used by electrical equipment.

Updated: 2026-10-27. Drawing use: SLD, Schematic. Reference families: IEEE / ANSI.

## What it represents

Monitors the density of a medium used by electrical equipment.
In a drafting package, connect this reference to the density sensor and monitored compartment. The associated drawing should trace the density alarm, lockout or operating permission; the number identifies the role and does not specify the terminal arrangement, ratings or operating settings.

## How to read it

- Identify the density sensor and monitored compartment.
- Trace the density alarm, lockout or operating permission.

## Drawing checklist

- Label the density sensor and monitored compartment.
- Cross-reference the density alarm, lockout or operating permission.
- Identify the device tag, manual revision and logic drawing that define this implementation.

## Important distinction

Density is distinct from pressure; temperature-compensated gas-density supervision should not be relabelled as 63 solely because a gauge is present.

## Facts

- ANSI / IEEE function number: 61
- Drawing context: The density sensor and monitored compartment
- Application scope: Protection or apparatus-control role; exact implementation is defined by the equipment documentation.
