## What it represents

The four-position maintained selector form supports four stable selections tied to a documented contact table. Position order matters when interpreting mode combinations, but physical rotation alone does not identify connected circuits.
This is a convention-specific lookup based on the publisher's IEEE-labelled preview. The geometry here is independently drawn to explain the connection or operation; it is not a certified reproduction of the standard graphic.

## How to read it

- Compare the drawing position order to the operator faceplate.
- Read the selected library and the project legend together. A vendor block identifier is meaningful within its named library and is not a universal standard-symbol code.

## Drawing checklist

- Name four positions
- Provide switching schedule
- Link operator/contact tags

## Important distinction

Four stable positions do not necessarily mean four contact poles.
