## What it represents

The four-position key-selector form combines multiple operating selections with a keyed mechanism. Its schematic references need consistent position numbering and the documented permissions for inserting or removing the key.
This is a convention-specific lookup based on the publisher's IEEE-labelled preview. The geometry here is independently drawn to explain the connection or operation; it is not a certified reproduction of the standard graphic.

## How to read it

- Follow each position through the linked contact schedule.
- Read the selected library and the project legend together. A vendor block identifier is meaningful within its named library and is not a universal standard-symbol code.

## Drawing checklist

- State position sequence
- Record key-removal states
- Identify contact blocks

## Important distinction

A multi-position key operator is not the same arrangement as several independent key switches.
