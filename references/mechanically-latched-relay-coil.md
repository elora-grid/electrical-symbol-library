# Mechanically latched relay coil

A mechanically latched relay retains a documented state after the initiating electrical command is removed.

## What it represents

A mechanically latched relay retains a documented state after the initiating electrical command is removed. The schematic needs both the operating and reset mechanism so the retained state can be understood.

## How to read it

- Identify the reset or unlatching path instead of assuming removal of coil power releases the contacts.
- The preview is an original explanation of this function. Match the actual drawing convention to its legend and the selected equipment documentation.

## Drawing checklist

- Label operating coil
- Show reset or unlatch action
- Cross-reference retained contacts

## Important distinction

A latched relay retains state; a conventional monostable relay returns when its operating condition is removed.
