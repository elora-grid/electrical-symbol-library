## What it represents

Supervises a DC load condition as part of a documented reclosing arrangement.
In a drafting package, connect this reference to the DC load measurement and open-circuit supervision. The associated drawing should trace the controlled DC breaker reclose path; the number identifies the role and does not specify the terminal arrangement, ratings or operating settings.
This designation is useful when reading machine and legacy control drawings. Retain the documented function on an existing drawing and consult the original equipment manual before assigning it to a new design.

## How to read it

- Identify the DC load measurement and open-circuit supervision.
- Trace the controlled DC breaker reclose path.

## Drawing checklist

- Label the DC load measurement and open-circuit supervision.
- Cross-reference the controlled DC breaker reclose path.
- Identify the device tag, manual revision and logic drawing that define this implementation.

## Important distinction

DC load-measuring reclosing is a specialist scheme and should not be inferred from an AC autoreclose 79 label.

## Facts

- ANSI / IEEE function number: 82
