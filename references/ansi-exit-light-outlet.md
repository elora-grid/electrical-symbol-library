# ANSI exit light outlet plan symbol

US plan symbol for an exit sign fixture, a circle or box with an X or EXIT text and direction arrows.

[Canonical reference](https://eloragrid.ai/symbols/ansi-exit-light-outlet) · [Structured record](../entries/ansi-exit-light-outlet.json) · [All references](README.md)

Updated: 2026-10-28. Drawing use: GA. Reference families: IEEE / ANSI.

Graphical convention: IEEE / ANSI. Exit light outlet.

## What it represents

US plans often mark exit signs with a circle containing an X, or a small rectangle with direction arrows, and a note for single or double face. The arrows show the chevrons to be installed on the sign.
Exit fixtures connect to the emergency branch circuit or contain batteries. The plan should state which, so the installer runs the correct circuit. The symbol does not give the face count unless noted, and it does not indicate the power source by itself.

## How to read it

- Check face and chevron notes.
- Identify emergency source.

## Drawing checklist

- State faces and chevrons.
- Identify power source.
- Coordinate with egress plan.

## Important distinction

The IEC-style exit sign plan mark serves the same purpose under a different convention.

## Facts

- Graphic form: Circle with X or box with arrows
