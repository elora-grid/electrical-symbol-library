# Switchgear panel

## What it represents

A switchgear-panel object represents the equipment envelope and interfaces used when arranging a switchroom or substation. The manufacturer and panel configuration establish the physical dimensions, cable entries, access sides and other installation information.

## How to read it

- Read plan and elevation views together.
- Identify the actual panel configuration before placing its footprint.

## Drawing checklist

- Reference the current product GA.
- Identify cable interfaces and access sides.
- Link the SLD equipment identifier.

## Important distinction

The panel envelope is a physical object; the breaker or switch symbol inside an SLD is an electrical representation.
