# Running-hours meter

A running-hours meter accumulates elapsed time while its specified enabling condition is active.

## What it represents

A running-hours meter accumulates elapsed time while its specified enabling condition is active. The schematic must show what condition is counted, such as a running feedback contact or an energised supply.

## How to read it

- An energised meter supply and actual machine running are not always the same condition.
- The preview is an original explanation of this function. Match the actual drawing convention to its legend and the selected equipment documentation.

## Drawing checklist

- Show enabling contact
- Name counted condition
- Reference reset/retention behaviour

## Important distinction

A running-hours meter measures duration; an operation counter counts events.
