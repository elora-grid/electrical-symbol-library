## What it represents

A redundancy module decouples documented power-supply inputs before they feed a common load circuit. The drawing shows each source input and the combined output so the redundancy arrangement is reviewable.

## How to read it

- Check each source's ability to supply the required load under the defined operating condition.
- The preview is an original explanation of this function. Match the actual drawing convention to its legend and the selected equipment documentation.

## Drawing checklist

- Show both source inputs
- Identify common output
- Reference monitoring/decoupling behaviour

## Important distinction

Two parallel supplies alone do not establish the same decoupling function as a redundancy module.
