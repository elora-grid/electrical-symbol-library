## What it represents

The latching relay form identifies an operating element whose mechanism retains a documented state. Its reset or release representation completes the circuit-reading sequence; removing the initiating command may not restore the initial position.
This is a convention-specific lookup based on the publisher's IEEE-labelled preview. The geometry here is independently drawn to explain the connection or operation; it is not a certified reproduction of the standard graphic.

## How to read it

- Find the reset path before deciding the state after the command ends.
- Read the selected library and the project legend together. A vendor block identifier is meaningful within its named library and is not a universal standard-symbol code.

## Drawing checklist

- Identify latch coil
- Show reset/unlatch element
- State retained contact position

## Important distinction

Mechanical retention and an electrical seal-in circuit achieve persistence through different arrangements.
