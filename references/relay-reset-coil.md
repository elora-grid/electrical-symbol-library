# Relay reset coil

A reset coil releases or changes the retained state of its associated latching relay.

[Canonical reference](https://eloragrid.ai/symbols/relay-reset-coil) · [Structured record](../entries/relay-reset-coil.json) · [All references](README.md)

## What it represents

A reset coil releases or changes the retained state of its associated latching relay. The shared device identity links this coil to the latch mechanism and contacts elsewhere on the schematic.

## How to read it

- Trace the reset command to the specific retained device.

## Drawing checklist

- Match relay tag
- State reset coil voltage
- Show reset interlocks

## Important distinction

A reset coil is not a second unrelated relay simply because it is drawn on another rung.
