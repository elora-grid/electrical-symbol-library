# Temperature measuring transducer

A temperature transducer converts a documented temperature-sensor input into an instrument signal.

## What it represents

A temperature transducer converts a documented temperature-sensor input into an instrument signal. The drawing identifies sensor type, conductor arrangement, supply and output loop.

## How to read it

- Confirm the selected RTD or thermocouple configuration before tracing the output scaling.
- The preview is an original explanation of this function. Match the actual drawing convention to its legend and the selected equipment documentation.

## Drawing checklist

- Name sensor type
- Show input conductor count
- State output range and scaling

## Important distinction

A transducer converts a measurement signal; a temperature switch produces a discrete condition.
