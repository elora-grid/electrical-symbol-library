## What it represents

The reset-coil form is a separately drawn operating element of the associated latch relay. Its tag ties it to the retained mechanism rather than to a new unrelated relay, even if the reset appears on another rung.
This is a convention-specific lookup based on the publisher's IEEE-labelled preview. The geometry here is independently drawn to explain the connection or operation; it is not a certified reproduction of the standard graphic.

## How to read it

- Follow the reset command to the matching latch-device reference.
- Read the selected library and the project legend together. A vendor block identifier is meaningful within its named library and is not a universal standard-symbol code.

## Drawing checklist

- Match latch/reset tag
- State reset supply
- Reference controlled contacts

## Important distinction

A separately drawn reset coil is not an extra set of power contacts.
