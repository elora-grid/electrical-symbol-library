## What it represents

This reference locates four-point current measurement selector in Autodesk's IEEE-oriented miscellaneous switches family. This representation identifies selection among four current-measurement points. The additional measurement point expands the selected current-input circuits while retaining a common meter. Each position therefore needs an unambiguous circuit identity. The public library uses HSW1S95 for its horizontal representation; this is a vendor block name, not an IEEE standards symbol number.
Read the operating mechanism and the contact reference state together. Cross-reference every associated contact to the same device and show which movement, signal or reset changes its condition; the symbol alone does not establish the complete switching sequence.
Provide all four measurement references and the actual terminal scheme. A voltage selector with the same number of positions is not an interchangeable current-measurement switch.
