# Bolted connecting link, open

A bolted connecting link drawn removed, showing a deliberate open point that needs tools and a dead circuit to close.

[Canonical reference](https://eloragrid.ai/symbols/bolted-link-open) · [Structured record](../entries/bolted-link-open.json) · [All references](README.md)

Updated: 2026-10-28. Drawing use: SLD, Schematic. Reference families: IEC, IEEE / ANSI.

## What it represents

The open link shows a planned open point in a circuit. Network diagrams use it to show normally open points between feeders, and switchboards use it for sections that are kept separated. The link may be stored beside the terminals or removed entirely.
Because a link cannot be closed under load or onto a fault, an open link is a firm separation and should not be confused with a normally open switch that can be operated in service. Check the operating procedure before assuming it can be used for transfer.

## How to read it

- Do not read the open link as a switchable tie.
- Check whether the link is stored nearby or removed.

## Drawing checklist

- State why the link is open.
- Identify where the removed link is kept.
- Distinguish open links from normally open switches.

## Important distinction

An open link is closed only when dead; a normally open switch can be closed in service.

## Facts

- Graphic cue: Two terminal points with the link bar absent or set aside
- Operation: Closed only with the circuit dead
