# Diode terminal block

A diode terminal includes a semiconductor diode in a documented terminal path.

## What it represents

A diode terminal includes a semiconductor diode in a documented terminal path. Polarity and the intended protective or decoupling function must remain explicit in the wiring schematic.

## How to read it

- Read anode and cathode connections from the actual terminal diagram.
- The preview is an original explanation of this function. Match the actual drawing convention to its legend and the selected equipment documentation.

## Drawing checklist

- Mark diode direction
- Name terminal connections
- Reference voltage/current rating

## Important distinction

A diode terminal is different from a feed-through terminal even if its physical housing is similar.
