# Minimum-current monitoring relay

A minimum-current relay operates according to a configured low-current condition.

[Canonical reference](https://eloragrid.ai/symbols/minimum-current-monitoring-relay) · [Structured record](../entries/minimum-current-monitoring-relay.json) · [All references](README.md)

Updated: 2026-10-27. Drawing use: SLD, Schematic. Reference families: Manufacturer.

## What it represents

A minimum-current relay operates according to a configured low-current condition. Control drawings must identify whether it supervises an operating load, a permissive or another circuit.

- Check how the relay handles zero current during intentional shutdown.

## Drawing checklist

- Name supervised circuit
- Reference enable condition
- State threshold and delay

## Important distinction

Low current can be an intentional stopped state; the control logic defines when it is abnormal.
