## What it represents

The tapped-secondary CT form marks alternative documented secondary connection points. The connected tap pair determines the operating transformation ratio; unused terminals remain subject to the actual transformer instructions rather than a generic drawing rule.
This is a convention-specific lookup based on the publisher's IEEE-labelled preview. The geometry here is independently drawn to explain the connection or operation; it is not a certified reproduction of the standard graphic.

## How to read it

- Read the operational ratio from the wired tap combination.
- Read the selected library and the project legend together. A vendor block identifier is meaningful within its named library and is not a universal standard-symbol code.

## Drawing checklist

- Label tap terminals
- State selected ratio
- Reference unused-tap instructions

## Important distinction

A winding tap selects a documented connection ratio; it is not another independent measurement core.
