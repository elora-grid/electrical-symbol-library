## What it represents

The IEEE-oriented disconnector form identifies a separable power-circuit path. Its operating state and main-device tag guide the reader to the isolation and interlocking information; electrical duty must be established from the specified equipment.
This is a convention-specific lookup based on the publisher's IEEE-labelled preview. The geometry here is independently drawn to explain the connection or operation; it is not a certified reproduction of the standard graphic.

## How to read it

- Read a shown gap as a documented contact state, not a full operating instruction.
- Read the selected library and the project legend together. A vendor block identifier is meaningful within its named library and is not a universal standard-symbol code.

## Drawing checklist

- Name disconnector
- State reference position
- Link electrical duty/interlocks

## Important distinction

A disconnector's isolation function is different from a protective device's automatic fault interruption.
