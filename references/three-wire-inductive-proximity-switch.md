# Three-wire inductive proximity switch

A three-wire inductive proximity switch uses separate supply, common and output conductors.

## What it represents

A three-wire inductive proximity switch uses separate supply, common and output conductors. Its output polarity and load connection must match the receiving input module.

## How to read it

- Follow the output common and receiving input polarity together.
- The preview is an original explanation of this function. Match the actual drawing convention to its legend and the selected equipment documentation.

## Drawing checklist

- Name three terminals
- State PNP or NPN as specified
- Reference PLC input compatibility

## Important distinction

Three-wire construction describes wiring; NO or NC describes the output's documented switching behaviour.
