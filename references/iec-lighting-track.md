# Lighting track plan mark

Plan mark for a lighting track that carries adapters for movable luminaires, drawn as a double line.

[Canonical reference](https://eloragrid.ai/symbols/iec-lighting-track) · [Structured record](../entries/iec-lighting-track.json) · [All references](README.md)

Updated: 2026-10-28. Drawing use: GA. Reference families: IEC.

Graphical convention: IEC. Lighting track.

## What it represents

Lighting tracks are drawn as a double line or a line with regular cross ticks along the track run, with spotlights attached as separate symbols. The track is fed at one end or mid-point, and multi-circuit tracks allow luminaires to be assigned to different circuits.
The plan shows track length and feed point, which the installer needs to order sections and end caps. Multi-circuit tracks are tagged with the number of circuits. The track symbol does not show how many luminaires will be clipped on in use. Loading is planned from the schedule.

## How to read it

- Find the feed point.
- Read circuit count for multi-circuit track.

## Drawing checklist

- State track length.
- State circuits.
- Show feed point.

## Important distinction

A linear luminaire emits light along its length; a track only carries adapters for separate luminaires.

## Facts

- Graphic form: Double line with ticks
- Fed from: End or centre feed point
