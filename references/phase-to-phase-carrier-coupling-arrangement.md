## What it represents

Shows the documented carrier coupling path associated with two selected phase conductors. A protection communication interface carries information between circuit ends or couples a communication signal to a primary line. Its signal path is different from the power-current path even when both use part of the same installation.
In a switchyard line bay, carrier-coupling equipment can connect a protection communication terminal to the transmission conductor. Fiber-based protection uses another physical path but still needs named endpoints and channel supervision. For this reference, the drawing identifies “Two phase coupling interfaces” at the input and “Phase-to-phase carrier path” at the output. Both coupling interfaces need identification.
