# Inductive position sensor

An inductive position sensor uses an electromagnetic interaction to infer a target's position.

## What it represents

An inductive position sensor uses an electromagnetic interaction to infer a target's position.
A control system can monitor a selected metallic target arrangement with its matching sensing circuit.
Identify the target and sensing-coil arrangement, then label the position-related output. The selected design derives information from an electromagnetic interaction with the target. Do not replace it with a generic on/off proximity-switch symbol if the intended output is a continuous position measurement. This is original functional artwork, not a certified standard graphic or device pinout.

## How to read it

- Identify the target material and mechanical arrangement.
- Show the measured axis or movement.
- Reference the selected sensing circuit and calibration requirements.
- Continuous position measurement is different from a simple proximity switch's on/off output.
