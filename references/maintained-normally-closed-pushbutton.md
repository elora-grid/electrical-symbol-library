# Maintained normally-closed pushbutton

A maintained NC pushbutton retains its actuated open state until the documented return action.

Updated: 2026-10-27. Drawing use: Schematic. Reference families: IEC, Manufacturer.

## What it represents

A maintained NC pushbutton retains its actuated open state until the documented return action. This affects permissive and stopping circuits that depend on contact continuity.

## How to read it

- Determine how the operator returns to the reference position.
- The preview is an original explanation of this function. Match the actual drawing convention to its legend and the selected equipment documentation.

## Drawing checklist

- Label retained state
- Show contact terminal numbers
- Reference return mechanism

## Important distinction

Maintained NC operation does not alone establish an emergency-stop safety function.
