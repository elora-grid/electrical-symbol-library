## What it represents

This reference locates maximum-current monitoring relay in Autodesk's IEEE-oriented current protection relays family. A maximum-current relay changes its output when the measured current meets a configured high-current condition. Its schematic separates measurement, auxiliary power and relay outputs. The public library uses HCR1F25 for its horizontal representation; this is a vendor block name, not an IEEE standards symbol number.
