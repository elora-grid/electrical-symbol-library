## What it represents

A manually reset counter relay records qualifying events and retains a count until the documented reset action. Event input, count condition and reset control should be identifiable on the drawing.

## How to read it

- Count events at the configured input rather than assuming every power cycle is an event.
- The preview is an original explanation of this function. Match the actual drawing convention to its legend and the selected equipment documentation.

## Drawing checklist

- Label count input
- Show manual reset
- Reference preset and output function

## Important distinction

A counter accumulates events; a timer measures duration.
