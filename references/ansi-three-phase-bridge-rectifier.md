## What it represents

This reference locates three-phase bridge rectifier in Autodesk's IEEE-oriented semiconductor components family. A three-phase bridge rectifier converts a documented three-phase AC input into a DC output. Its input phase terminals and DC polarity must be identifiable. The public library uses HDI1V5 for its horizontal representation; this is a vendor block name, not an IEEE standards symbol number.
