# Transformer envelope

A generic transformer object for locating the equipment and its documented interfaces.

[Canonical reference](https://eloragrid.ai/objects/transformer-envelope) · [Structured record](../entries/transformer-envelope.json) · [All references](README.md)

Updated: 2026-10-27. Drawing use: GA. Reference families: Manufacturer.

## What it represents

A transformer envelope connects a GA placement to a selected transformer and its manufacturer drawing. The physical information can include connection locations, accessories and maintenance or installation requirements, all of which depend on the product and application.

## How to read it

- Distinguish the equipment envelope from any separately documented access area.
- Use the actual manufacturer view and reference orientation.

## Drawing checklist

- Reference the selected transformer GA.
- Identify connection interfaces and accessories.
- Link ratings to the equipment schedule.

## Important distinction

An SLD transformer symbol is not a scaled footprint. A generic envelope has no model-specific dimensions.

## Facts

- Object type: Generic equipment reference
- Dimensions: Use the exact manufacturer/model drawing
