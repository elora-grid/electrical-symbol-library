## What it represents

This form combines a disconnector power path with a locking provision. The drawing reader needs the lockable position and mechanism reference so a lock mark does not become an unsupported claim about all possible device positions.
This is a convention-specific lookup based on the publisher's IEEE-labelled preview. The geometry here is independently drawn to explain the connection or operation; it is not a certified reproduction of the standard graphic.

## How to read it

- Match the lock reference to the operator assembly.
- Read the selected library and the project legend together. A vendor block identifier is meaningful within its named library and is not a universal standard-symbol code.

## Drawing checklist

- State lockable position
- Identify mechanism
- Cross-reference interlocks

## Important distinction

Lockability describes mechanical retention; it does not increase electrical interrupting capability.
