# DC uninterruptible power supply

A DC UPS maintains a documented DC load supply during a specified input interruption using an associated energy store.

## What it represents

A DC UPS maintains a documented DC load supply during a specified input interruption using an associated energy store. The drawing identifies normal supply, storage and load paths plus monitoring signals.

## How to read it

- Trace the battery or capacitor module separately from the DC load feed.
- The preview is an original explanation of this function. Match the actual drawing convention to its legend and the selected equipment documentation.

## Drawing checklist

- Show normal input
- Show storage connection
- Reference load and autonomy data

## Important distinction

A DC UPS feeds DC loads; an AC UPS includes a documented AC output path.
