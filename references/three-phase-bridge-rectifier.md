# Three-phase bridge rectifier

A three-phase bridge rectifier converts a documented three-phase AC input into a DC output.

[Canonical reference](https://eloragrid.ai/symbols/three-phase-bridge-rectifier) · [Structured record](../entries/three-phase-bridge-rectifier.json) · [All references](README.md)

Updated: 2026-10-27. Drawing use: Schematic. Reference families: IEC, Manufacturer.

## What it represents

A three-phase bridge rectifier converts a documented three-phase AC input into a DC output. Its input phase terminals and DC polarity must be identifiable.

## How to read it

- Check the rectifier's output and any smoothing network as separate circuit elements.
- The preview is an original explanation of this function. Match the actual drawing convention to its legend and the selected equipment documentation.

## Drawing checklist

- Label three AC phases
- Mark DC polarity
- Reference rectifier ratings

## Important distinction

Three-phase rectification differs from a single-phase bridge connection.
