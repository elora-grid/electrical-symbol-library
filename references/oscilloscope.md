# Oscilloscope

Instrument that displays the waveform of a signal against time, drawn with a waveform inside the instrument outline.

[Canonical reference](https://eloragrid.ai/symbols/oscilloscope) · [Structured record](../entries/oscilloscope.json) · [All references](README.md)

Updated: 2026-10-28. Drawing use: Schematic. Reference families: IEC.

## What it represents

An oscilloscope displays how a voltage or current changes over time. In drawings it appears in test set-ups, laboratory panels and commissioning procedures, with its probe points shown so readers know exactly where waveforms are to be captured.
The symbol does not show probe type or reference. Connecting an earth-referenced scope ground lead to a live point in a power circuit can short the circuit, so differential probes or isolated channels must be specified in the procedure rather than assumed from the symbol.

## How to read it

- Identify the probe reference point for each channel.
- Check whether differential probes are required.

## Drawing checklist

- Mark probe points
- State probe type
- Note bandwidth if relevant

## Important distinction

An oscilloscope shows a waveform shape; a disturbance recorder stores triggered records for later analysis.

## Facts

- Displayed quantity: Signal amplitude against time
- Main risk: Earth-referenced probe leads on live circuits
- Preview: Independent educational concept; consult the applicable standard and project legend for the exact graphic
