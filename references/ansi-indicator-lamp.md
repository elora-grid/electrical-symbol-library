## What it represents

The incandescent lamp form identifies a visual indication load in the named vendor library. Its colour, supply and indicated condition are separate annotations; illumination must be interpreted from the connected signal path.
This is a convention-specific lookup based on the publisher's IEEE-labelled preview. The geometry here is independently drawn to explain the connection or operation; it is not a certified reproduction of the standard graphic.

## How to read it

- Follow the signal that energises the lamp.
- Read the selected library and the project legend together. A vendor block identifier is meaningful within its named library and is not a universal standard-symbol code.

## Drawing checklist

- State lamp voltage/colour
- Name indicated condition
- Reference signal contact

## Important distinction

A lamp lit from a command circuit does not necessarily confirm the commanded equipment has moved.
