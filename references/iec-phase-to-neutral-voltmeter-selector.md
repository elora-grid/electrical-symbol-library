## What it represents

This representation identifies selection among phase-to-neutral voltage measurement connections. The meter is connected to the selected phase relative to the documented neutral or reference point. That connection differs from measuring between two phase conductors.
Show the reference terminal and each selectable measurement path. The position table should make clear which reading the operator receives at each position.

## How to read it

- Show the neutral/reference connection and each selected phase in the position table.
- Phase-to-neutral and phase-to-phase measurements have different connection paths.
