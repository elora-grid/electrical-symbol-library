# Two-way light switch plan mark

Plan mark for a two-way switch used in pairs so one lighting group can be switched from two places.

[Canonical reference](https://eloragrid.ai/symbols/iec-two-way-light-switch) · [Structured record](../entries/iec-two-way-light-switch.json) · [All references](README.md)

Updated: 2026-10-28. Drawing use: GA. Reference families: IEC.

Graphical convention: IEC. Two-way switch.

## What it represents

Two-way switches are installed in pairs at either end of a corridor or staircase so either switch changes the state of the lights. The IEC-style plan form draws the switch circle with strokes in two opposite directions, each with a tick, showing the changeover action.
On a plan the pair is linked by a switching line to the luminaire group. The electrician reads the pair to run strappers between the two switches; where an intermediate switch is shown between them, a third location can also control the lights.
The symbol does not show the wiring method, which can be conventional strappers or a converted arrangement. It also does not tell you the gang count unless written.

## How to read it

- Expect two-way switches in pairs; a single two-way switch usually signals a drafting error or a spare.
- Look for an intermediate switch between the pair on long runs.

## Drawing checklist

- Show both switch positions and the controlled luminaires.
- Mark any intermediate switches.
- Note gang count where plates are shared.

## Important distinction

In US terminology this is a three-way switch; the US four-way switch corresponds to the IEC intermediate switch.

## Facts

- Operation: Changeover contact, used in pairs
- US equivalent term: Three-way switch
