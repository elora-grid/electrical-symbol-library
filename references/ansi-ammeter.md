## What it represents

The ammeter form identifies current indication from a direct or instrument-transformer measurement. Current input and auxiliary power connections serve different functions, so a compact instrument circle is read with its terminal diagram.
This is a convention-specific lookup based on the publisher's IEEE-labelled preview. The geometry here is independently drawn to explain the connection or operation; it is not a certified reproduction of the standard graphic.

## How to read it

- Trace the current circuit and CT reference together.
- Read the selected library and the project legend together. A vendor block identifier is meaningful within its named library and is not a universal standard-symbol code.

## Drawing checklist

- Identify current input
- State direct/CT scaling
- Reference secondary test connections

## Important distinction

An ammeter is a measuring instrument rather than an overcurrent protective function number.
