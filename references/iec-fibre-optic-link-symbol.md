# Fibre-optic link symbol

Symbol for an optical fibre link between devices, a line with a fibre mark, often with media converters at each end.

[Canonical reference](https://eloragrid.ai/symbols/iec-fibre-optic-link-symbol) · [Structured record](../entries/iec-fibre-optic-link-symbol.json) · [All references](README.md)

Updated: 2026-10-28. Drawing use: Schematic, GA. Reference families: IEC.

Graphical convention: IEC. Optical fibre link.

## What it represents

Fibre-optic links are drawn as a line carrying a fibre indication, such as a small loop, a wavy section or the tag FO, between the devices they connect. Network diagrams also show the fibre count and type, such as 12-core single-mode.
Electrical drawings use fibre links for substation communications, between buildings and through areas with electrical noise or earth potential rise, because fibre gives galvanic isolation. The symbol is often terminated in a media converter or switch fibre port. The symbol does not specify connectors, loss budget or route. The fibre schedule and test results cover these.

## How to read it

- Read core count and fibre type.
- Find the termination at each end.

## Drawing checklist

- State fibre type and cores.
- Show terminations.
- Reference loss test results.

## Important distinction

A copper data cable has no isolation benefit; the fibre link isolates the two ends electrically.

## Facts

- Benefit: Galvanic isolation and noise immunity
- Key data: Fibre type and core count
- Exact standard graphic: Not reproduced here; confirm the form against IEC 60617 and the project legend
