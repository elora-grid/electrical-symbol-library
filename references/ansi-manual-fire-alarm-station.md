# ANSI manual fire alarm station plan symbol

US-style plan symbol for a manual fire alarm pull station, commonly a square with an F, at each exit.

[Canonical reference](https://eloragrid.ai/symbols/ansi-manual-fire-alarm-station) · [Structured record](../entries/ansi-manual-fire-alarm-station.json) · [All references](README.md)

Updated: 2026-10-28. Drawing use: GA. Reference families: IEEE / ANSI.

Graphical convention: IEEE / ANSI. Manual fire alarm station.

## What it represents

US plans mark manual pull stations with a square containing F or a pull-station shape, located within reach of each exit door. Single-action and double-action types are distinguished in the device schedule.
The plan is used to check that pull stations are within the required distance of each exit and at the required height. Protective covers may be specified where malicious activation is a risk. The symbol does not show the action type or cover.

## How to read it

- Check location near each exit.
- Check covers where specified.

## Drawing checklist

- Tag address.
- State action type.
- Give mounting height.

## Important distinction

The IEC manual call point is a break-glass or resettable push; the US pull station is operated by pulling a handle.

## Facts

- Graphic form: Square with F
- Operation: Pull handle, single or double action
