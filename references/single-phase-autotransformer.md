# Single-phase autotransformer

A single-phase autotransformer uses a winding portion shared electrically by its input and output circuits.

[Canonical reference](https://eloragrid.ai/symbols/single-phase-autotransformer) · [Structured record](../entries/single-phase-autotransformer.json) · [All references](README.md)

Updated: 2026-10-27. Drawing use: SLD, Schematic. Reference families: IEC, Manufacturer.

## What it represents

A single-phase autotransformer uses a winding portion shared electrically by its input and output circuits. Its drawing must make the common connection clear because it does not provide winding separation like a two-winding transformer.

## How to read it

- Trace the common winding terminal and identify the supply and load tap positions.
- The preview is an original explanation of this function. Match the actual drawing convention to its legend and the selected equipment documentation.

## Drawing checklist

- State input and output voltages
- Show common winding connection
- Reference tap and rating data

## Important distinction

An autotransformer is not an isolating two-winding transformer.
