# Open-delta winding connection

An open-delta arrangement uses an incomplete delta connection for a specified transformer or measurement purpose.

## What it represents

An open-delta arrangement uses an incomplete delta connection for a specified transformer or measurement purpose. The absent winding or open connection must be visible rather than interpreted as an accidental drawing omission.

## How to read it

- Identify the actual application and its documented winding arrangement.

## Drawing checklist

- Show open portion
- Name connected terminals
- Reference applicable rating or measurement scheme

## Important distinction

Open delta and broken-delta residual-voltage circuits describe different application contexts; the drawing must say which is intended.
