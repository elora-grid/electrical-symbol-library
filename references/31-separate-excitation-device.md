# Separate excitation device

Connects or controls a separately supplied excitation arrangement for a machine.

Updated: 2026-10-27. Drawing use: SLD, Schematic. Reference families: IEEE / ANSI.

## What it represents

Connects or controls a separately supplied excitation arrangement for a machine.
In a drafting package, connect this reference to the separate excitation supply and machine field connection. The associated drawing should trace the excitation switching command and sequence references; the number identifies the role and does not specify the terminal arrangement, ratings or operating settings.
This designation is useful when reading machine and legacy control drawings. Retain the documented function on an existing drawing and consult the original equipment manual before assigning it to a new design.

## How to read it

- Identify the separate excitation supply and machine field connection.
- Trace the excitation switching command and sequence references.

## Drawing checklist

- Label the separate excitation supply and machine field connection.
- Cross-reference the excitation switching command and sequence references.
- Identify the device tag, manual revision and logic drawing that define this implementation.

## Important distinction

This specialist machine-control reference should be interpreted with the excitation drawing; device 41 identifies a field breaker.
