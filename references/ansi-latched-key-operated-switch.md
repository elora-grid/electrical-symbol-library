## What it represents

This reference locates latched key-operated switch in Autodesk's IEEE-oriented miscellaneous switches family. A latched key-operated switch retains its commanded position according to the selected mechanism. The drawing should specify how the latched position is released and where the key is removable. The public library uses HPB11KSL for its horizontal representation; this is a vendor block name, not an IEEE standards symbol number.
Read the operating mechanism and the contact reference state together. Cross-reference every associated contact to the same device and show which movement, signal or reset changes its condition; the symbol alone does not establish the complete switching sequence.
Separate the mechanical retention from any electrical seal-in circuit. Mechanically latched operation is different from a relay holding circuit. The linked functional counterpart explains the same operating role in its own drawing context; agreement of every detailed convention mark is not asserted.
