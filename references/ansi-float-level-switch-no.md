## What it represents

The float-operated NO form connects a discrete electrical action to a defined liquid-level mechanism. The drawing must identify the vessel or location and the direction of level movement that actuates the contact.
This is a convention-specific lookup based on the publisher's IEEE-labelled preview. The geometry here is independently drawn to explain the connection or operation; it is not a certified reproduction of the standard graphic.

## How to read it

- Match the electrical reference state to the documented float orientation.
- Read the selected library and the project legend together. A vendor block identifier is meaningful within its named library and is not a universal standard-symbol code.

## Drawing checklist

- Name vessel/location
- State level direction
- Reference operating/reset levels

## Important distinction

Float level sensing is different from a continuous analog level transmitter.
