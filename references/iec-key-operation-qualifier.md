# Key-operation qualifier

A key-operation qualifier identifies a mechanism requiring the specified key action.

## What it represents

A key-operation qualifier identifies a mechanism requiring the specified key action. A key may control whether a mechanism can be moved or which positions are available. That access role is separate from the contact state produced by the movement.
Identify the keyed operator and any related locks through their tags. For an interlocking sequence, reference the sequence document instead of relying on one key-operation mark.

- Cross-reference the key sequence and any related locking devices.
