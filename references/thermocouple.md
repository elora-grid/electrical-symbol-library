# Thermocouple

A thermocouple produces a temperature-dependent voltage associated with its dissimilar-metal junction system.

Updated: 2026-10-27. Drawing use: Schematic. Reference families: IEC, Manufacturer.

## What it represents

A thermocouple produces a temperature-dependent voltage associated with its dissimilar-metal junction system. Correct type, polarity and extension wiring matter when connecting it to an instrument.

## How to read it

- Trace the thermocouple terminals and specified extension cable together.
- The preview is an original explanation of this function. Match the actual drawing convention to its legend and the selected equipment documentation.

## Drawing checklist

- State thermocouple type
- Mark polarity
- Reference input and compensation arrangement

## Important distinction

A thermocouple generates a voltage signal; an RTD changes resistance.
