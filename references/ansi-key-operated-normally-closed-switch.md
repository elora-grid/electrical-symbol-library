## What it represents

This reference locates key-operated normally-closed switch in Autodesk's IEEE-oriented miscellaneous switches family. A key-operated NC switch opens its reference closed contact through the key mechanism. Its access and switching functions must be documented separately. The public library uses HPB12KS for its horizontal representation; this is a vendor block name, not an IEEE standards symbol number.
Read the operating mechanism and the contact reference state together. Cross-reference every associated contact to the same device and show which movement, signal or reset changes its condition; the symbol alone does not establish the complete switching sequence.
