# Variable resistor

A variable resistor provides a documented adjustable resistance in a circuit path.

[Canonical reference](https://eloragrid.ai/symbols/variable-resistor) · [Structured record](../entries/variable-resistor.json) · [All references](README.md)

Updated: 2026-10-27. Drawing use: SLD, Schematic. Reference families: IEC, Manufacturer.

## What it represents

A variable resistor provides a documented adjustable resistance in a circuit path. Its range, terminal usage and adjustment method must be stated when they affect the control function.

## How to read it

- Check whether the device is used as a two-terminal resistance or a three-terminal divider.
- The preview is an original explanation of this function. Match the actual drawing convention to its legend and the selected equipment documentation.

## Drawing checklist

- State resistance range
- Show connected terminals
- Reference adjustment method

## Important distinction

A variable resistor is a broader function than a three-terminal potentiometer connection.
