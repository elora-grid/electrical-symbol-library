## What it represents

The TRIAC form identifies a controlled bidirectional semiconductor path. Its main-terminal and gate references establish how the drive circuit is related to the AC load circuit, with operating details supplied by the selected component.
This is a convention-specific lookup based on the publisher's IEEE-labelled preview. The geometry here is independently drawn to explain the connection or operation; it is not a certified reproduction of the standard graphic.

## How to read it

- Use the component's main-terminal numbering to resolve the gate reference.
- Read the selected library and the project legend together. A vendor block identifier is meaningful within its named library and is not a universal standard-symbol code.

## Drawing checklist

- Label main terminals/gate
- Reference trigger circuit
- State load and voltage duty

## Important distinction

A TRIAC has a gate-controlled function unlike a DIAC triggering element.
