# Off-delay normally-open contact

An off-delay NO contact retains the documented operated state for an interval after the timer trigger is removed.

## What it represents

An off-delay NO contact retains the documented operated state for an interval after the timer trigger is removed. The actual timer timing chart establishes the switching sequence.

## How to read it

- Check the output's state during supply loss separately from normal trigger removal.
- The preview is an original explanation of this function. Match the actual drawing convention to its legend and the selected equipment documentation.

## Drawing checklist

- Identify timer reference
- Label delayed release
- Reference supply-loss state

## Important distinction

Off-delay release requires a stated sequence; the NO label alone only identifies the reference contact state.
