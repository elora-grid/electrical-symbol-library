## What it represents

A logic gate that inverts an inclusive-OR result.
On a schematic, identify the input truth convention and inverted output and trace the downstream logic and reset/permissive interface. Keep the component tag and signal/reference names consistent across the control drawing, terminal schedule and device documentation.
NOR is different from NAND because the underlying input combination is OR rather than AND.
Terminal letters describe electrical roles, not package pin numbers. Check the selected public datasheet for the actual pin assignment, polarity and any internally connected terminals before completing the drawing.
