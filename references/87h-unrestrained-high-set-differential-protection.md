## What it represents

Provides the documented high-set or unrestrained differential element in the cited relay family.
The drafting record should connect this function to the same protected-zone CT inputs and high-set element reference, then trace the unrestrained differential trip output. Keep the complete designation and equipment tag together so that the SLD, relay logic and terminal schedule describe the same implementation.
The cited mapping is a public manufacturer example (Eaton ETR family). Suffixes are not universal equivalences across products, and this reference supplies neither a protection setting nor certification of the selected scheme.

- Label the same protected-zone CT inputs and high-set element reference.
- Cross-reference the unrestrained differential trip output.
- Retain the complete suffix, selected device tag and manufacturer manual revision.

## Important distinction

An unrestrained high-set element differs from the percentage-restrained differential element and must retain its own setting reference.
