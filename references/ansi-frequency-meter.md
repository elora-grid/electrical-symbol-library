## What it represents

The frequency-meter form identifies the frequency of a specified measurement source. When several buses or generators appear on the drawing, the input path and selection switch determine which source is being indicated.
This is a convention-specific lookup based on the publisher's IEEE-labelled preview. The geometry here is independently drawn to explain the connection or operation; it is not a certified reproduction of the standard graphic.

## How to read it

- Read the source selection before interpreting the value.
- Read the selected library and the project legend together. A vendor block identifier is meaningful within its named library and is not a universal standard-symbol code.

## Drawing checklist

- Name measured source
- Reference input range
- Show source-selection wiring

## Important distinction

Frequency indication differs from an underfrequency relay's trip or load-shed criterion.
