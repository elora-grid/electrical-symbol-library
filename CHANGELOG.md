# Changelog

## 1.0.0 — 2026-10-14

First public dataset release: 1,095 electrical references, 305 public sources,
1,095 original SVG illustrations and an original R12 DXF concept-block pack.
The separate manufacturer directory contains 6,095 externally hosted CAD file
listings; manufacturer CAD bytes are not included.

Includes explicit IEC and ANSI/IEEE form metadata where supported, canonical
Elora citation URLs, per-entry JSON, compact search index, JSON Schemas,
dependency-free query examples, source/reuse notices, CC BY 4.0 original-content
licensing, MIT utility licensing, dataset citation, checksums, public-export
refresh tooling and validation/release workflows.

Editorial updates and new releases follow the same public Elora catalogue.
